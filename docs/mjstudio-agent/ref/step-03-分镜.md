> 加载时机：第三步。目标产物 = 每集一条 `POST /api/episodes`（集 + 四表）+ 每镜一条 `POST /api/shots`。
> 关联：ref/timing.md（时长）、SKILL.md 第六节（字段映射）。
> **本版本范围**：分镜环节只产出「集四表 + 镜头 11 项」。角色外貌/声线、场景布局与锚点、道具、BGM/音效明细等**资产明细归入后续扩展的资产环节，本版本不写 `/api/assets`**。

# 第三步 分镜（分镜师）

## 1. 职责
1. **先审剧本合理性**：逐集检查剧情、时长、节奏。时长不达标 / 剧情不完整 / 台词失衡 / 无剧情热点 → 打回剧本环节（stage=1），不进入分镜。
2. **把剧本切成镜头**（导演思维：镜头语言、节奏、情绪、转场）。
3. **产出本集资产白名单**（`episode.assetWhitelist`）：反复出现、需高度一致的内容（主角/固定房间/常用道具/BGM/技能特效）+ **所有有台词的角色**（哪怕一次性出场、只有一句台词）；仅**无台词**的纯群像/路人可不入。
4. **产出同场景机位切换表**（`episode.cameraSwitchTable`）、**音频出现点表**（`episode.audioCueTable`）、**台词清单 JSON**（`episode.dialogueList`）。
5. **逐镜落库**（`shot-upsert-many`），每镜 11 项字段齐全。

## 2. 镜头拆分规则（硬约束）
- **每镜 5~10 秒**；超 10 秒必拆，不足 5 秒必并，转场镜头同此（无 3~5 秒例外）
- 拆分法：按"一个动作 / 一个情绪节拍 / 几句对话"切；每镜时长 = 台词秒 + 动作秒
- 单集镜头数 ≈ 正文秒 ÷ 6~8（120 秒 ≈ 15~24 镜）

### 一镜一视频（防多分镜）
- 一个分镜 = 一个镜头 = 一个视频 = 一个机位；视频内禁止多分镜/场景跳变/机位切换
- **换场景 / 换面 / 换状态 = 必换分镜**（禁止"场景A→场景B""朝东→朝南""白天→夜晚"的镜内跳变）
- **同场景连续分镜强制换位**：必须换机位面 / 换景别 / 换人物站位状态，禁止"同机位同景别纯切"的无效分镜

## 3. 集四表（写进 `POST /api/episodes` 的四个 string 字段）

### 3.1 `assetWhitelist` 本集资产白名单
```markdown
- 角色:星野 / Momo / 记者 / 旁白（凡有台词必列，含一次性角色与旁白）
- 场景:观测站-白天-镜头朝东 / 观测站-夜晚-镜头朝南（按 区域×状态×面 列全）
- 道具:信号接收器
- BGM:旧时光（覆盖镜头1~6 约40s）/ 紧张追逐（覆盖镜头7~9 约22s）
```
- **场景必须按 状态 × 机位面 × 空间区域 三维拆分**，禁止只建一个"全景场景"；命名 `场景名-状态-面`
- 判断标准：剧本里某镜的**背景 + 机位朝向 + 状态**，必须能在白名单里找到对应组合；找不到 = 漏了，要补

### 3.2 `cameraSwitchTable` 同场景机位切换表（每集必填，含锚点声明）
```markdown
| 镜头 | 场景区域 | 场景状态 | 镜头朝向(面) | 景别 | 人物站位锚点 | 画面左 | 画面右 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 镜头1 | 观测站-主控室 | 白天 | 朝东(正面) | 中景 | 星野在门口(门在西墙),面朝屋内(东) | 北 | 南 |
| 镜头2 | 观测站-主控室 | 白天 | 朝南(左侧) | 近景 | 星野在门口(门在西墙),面朝屋内(东) | 东 | 西 |
```
- **锚点约定**：方位角 北=0°、东=90°、南=180°、西=270°，顺时针递增；镜头朝 θ° 拍时，**画面左 = θ-90°、画面右 = θ+90°**
- 人物站位与面朝方向（以场景标志物为锚点）**跨镜头绝对锁定**；变的是镜头，不是人物

### 3.3 `audioCueTable` 音频出现点表（每集必填）
```markdown
- BGM-旧时光: 镜头1 第0.0s 起播(全局00:00.0) → 镜头6 第8.0s 止(全局00:38.0)；静音段=镜头7~9
- BGM-紧张追逐: 镜头7 第0.0s 起播(全局00:38.0) → 镜头9 第4.5s 止(全局00:50.5)
- 音效-电流杂音: 镜头1~3 循环底噪(全局00:00.0 起,持续)
- 音效-信号叮咚: 镜头2 第3.2s 触发一次(全局00:09.2)
```
- 必须精确到 **镜头号 + 镜头内秒 + 全局秒**；禁止只写镜头区间
- BGM 曲目必须先在本集 `assetWhitelist` 中，且时长覆盖其被使用的全部镜头

### 3.4 `dialogueList` 台词清单（JSON 文本整段存入该字段）
```json
{
  "episode": 1,
  "lines": [
    {"seq":1,"shot":1,"character":"旁白","text":"春天来了，池塘里多了一群小小的小生命。","emotion":"温馨宁静","start_sec":1.0,"duration_sec":4.0,"end_sec":5.0},
    {"seq":2,"shot":2,"character":"星野","text":"咦，这里是哪儿？","emotion":"好奇","start_sec":6.5,"duration_sec":3.9,"end_sec":10.4}
  ]
}
```
- 字段固定 `seq/shot/character/text/emotion/start_sec/duration_sec/end_sec`，**不得含 file 字段**
- 台词文本与分镜时间轴**逐字对应**，不得增删改
- `start_sec/end_sec` = **全集累计秒**（由全局 TC 换算：句 start = Σ(该镜之前所有镜头时长) + 镜头内 start）

## 4. 镜头 11 项字段（→ shot 字段，缺一即不合格）
| # | 分镜字段 | shot 字段 |
|---|---|---|
| ① | 视频内容 | `videoContent` |
| ② | 首帧画面描述 | `firstFrameDesc` |
| ③ | 运镜（景别+机位+运镜） | 景别→`shotSize`，机位+运镜→`camera` |
| ④ | 空间方位 | `spatialPosition` |
| ⑤ | 资产引用 | 写进 `videoContent` 末尾一行 `【资产引用】[角色:星野][场景:观测站-白天-镜头朝东][道具:信号接收器]` |
| ⑥ | BGM | `bgm`（曲目名或"无"，必须在本集白名单） |
| ⑥b | BGM 起止秒点 | `bgmRange` |
| ⑦ | 全局时间码 TC | `timecode`（格式 `00:00.0~00:06.0`，前一镜 TC_out 顺延） |
| ⑧ | 镜头时间轴 | `timeline` |
| ⑨ | 发声约束 | `voiceConstraint` |
| ⑩ | 环境音效 / 触发点 | `ambientSfx` / `sfxRange` |
| ⑪ | 时长 / 转场 | `duration`（秒，5~10）/ `transition` |
| — | 镜头朝向（面） | `cameraFacing` |

### 4.1 镜头时间轴（`timeline`）写法
- 按内容切时间段，每段写清 `[start~end]` 做什么
- **每段四要素齐全**：① 拍摄方式（景别+机位+运镜）② 画面内容（谁在哪做什么/什么表情）③ 空间方位（角色在画面哪边、距对方多远）④ 环境氛围（光线/环境状态）；开场段必查 ③④
- **镜头首尾必须有内容**，禁止"无动作空白段"
- 台词句写在对应段内（`角色说:"台词"`）；**时间只写段标题一次**，句内禁止重复标注时间
- 无台词镜头同样要有阶段时间轴
- 正例：`[0.0~0.5s] 开场:中近景+平视+固定机位,鸭妈妈俯身凑近画面左下的小墨(约半身距离),午后水道,芦苇影在右,水面碎金反光;神情温和;无台词`
- 反例（禁止）：`[0.0~0.5s] 开场:鸭妈妈凑近小墨`（缺拍摄方式/空间方位/环境氛围）

### 4.2 时间轴精确性（四点，缺一即不合格）
1. **说话时机与姿态精确**：每句台词写明"以什么姿态说（边走边说/走停再说/站定说/边做边说/转身说）"
2. **走位可行性**：位移与时长匹配（步行约 1~1.5 m/s）；写明"从哪入画→沿什么路径→何时停步→停在距对方多远"；走不完就缩短距离或拆镜
3. **收尾段全在场角色状态**：逐人写清表情与反应（被挑衅/对峙方必须有明确神态动作），禁止"两人纵深对峙"式空洞描述
4. **入画与停步点明确**：入画时刻单独写清，与收尾段衔接

### 4.3 机位面 × 人物朝向自洽性（三关）
- **关1**：`镜头朝X` = 机位在 X 对面、向 X 拍摄。人物站位与面朝方向不变时，换机位面 → 人物相对镜头的朝向自动翻转：面朝 X → 背影；面朝机位方向 → 正脸；垂直 → 侧脸。**禁止机位换面后人物仍死盯镜头**
- **关2**：同场景同机位面的连续镜头，人物朝向必须一致；中途变化必须有"转身/别过脸去/侧过身"动作段交代
- **关3**：旁观者视线与人物体态一致（人物面朝东：北侧旁观者见侧影、东侧见正脸、西侧见背影）

### 4.4 机位面左右三角核验（四步，逐镜自检）
1. 读机位表的锚点（本面朝向=朝θ° / 画面左=θ-90° / 画面右=θ+90°）
2. 投影验算：把空间方位里每个锚点（标志物/人物站位）按绝对方位投到画面左/右/中央
3. 比对分镜写的"画面左/右/中央"是否与投影一致
4. 出画/入画方向不得与摆件位置冲突（摆件投影在画面左，却写"向画面右侧驶出绕过槐树"= 矛盾）

### 4.5 画面对象识别与空间方位精确性
- **独立资产判定**：凡满足任一条的对象必须独立成资产并写清区分特征 —— ① 参与剧情动作 ② 画面内存在同类/相似对象、观众须分辨"是哪一个" ③ 需跨镜一致 ④ 与角色空间交互或承载关键信息。禁止"其中一颗/旁边那个"式模糊指向
- **空间方位四要素**：① 参照系明确 ② 间距可感知（"约一个卵径""半臂距离""隔一张桌子"，禁止只说"相邻"）③ 动作指向明确到具体对象 ④ 下游无需猜测即可执行
- 正例：`卵A在画面左侧已裂开、卵B在画面右侧完整，两卵相距约一个卵径；[3.2~4.4s] 卵B裂开，小蝌蚪乙从卵B探出头`
- 反例：`画面中有两颗卵，其中一颗裂开，小蝌蚪乙从里面探出头`

### 4.6 转场规则
镜头间必须连贯，每镜标注转场（硬切/叠化/淡入淡出/闪白/摇移承接）；与情绪匹配：温馨→叠化/淡入，紧张→硬切，回忆→闪白/柔化。

### 4.7 运镜
默认固定机位；人物移动→跟镜头，聚焦情绪→推镜头，段落收尾→拉镜头，视线转移/扫视→摇镜头，情绪峰值名场面→环绕。**禁止**：人物静止乱晃、普通对话环绕、连续 3 个及以上运动镜头、推完立刻拉。特殊运镜每集 ≤ 6 处并注明动机。

## 5. 落库方式
```bash
# 1) 集 + 四表
python scripts/mj.py episode-upsert --episode-no 1 --name "第1集 信号" --duration 130 \
  --asset-whitelist-file 第1集_白名单.md \
  --camera-switch-table-file 第1集_机位表.md \
  --audio-cue-table-file 第1集_音频点表.md \
  --dialogue-list-file 第1集_台词.json

# 2) 镜头（shots.json 为对象数组，按 shotNo 幂等；重复执行=更新，不会产生重复镜头）
python scripts/mj.py shot-upsert-many --episode-no 1 --data-file 第1集_镜头.json
python scripts/mj.py shot-list --episode-id <上一步返回的 episodeId>   # 核对
```

`第1集_镜头.json` 数组元素示例（字段名严格用 camelCase）：

    "firstFrameDesc": "中景，星野半蹲在画面右下控制台前，侧身低头翻找，晨光从画面左上斜射，控制台阴影在左",

## 6. 场景组合齐全性反查（定稿后必做）
汇总本集每镜引用的 `[场景:xx-状态-面]`，去重得到"用到的场景组合集合"，与 `assetWhitelist` 中的场景清单对比 —— 被引用但未列入 → 补进白名单后再落库。

## 7. 台词三处同源
剧本 `content` / 镜头 `timeline` / 台词清单 `dialogueList` 三处台词必须一致。**任何一处改动必须同步改另外两处**，严禁只改一处。

## 8. 收尾
全部落库后进入 [3.1 分镜评审](step-03.1-分镜评审.md)；**评审通过后必须提交用户审核确认**，用户确认后本技能当前范围（三步）结束。
