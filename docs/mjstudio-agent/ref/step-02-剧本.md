# 第二步 剧本（编剧）

## 1. 职责
根据项目立项字段（世界观、`totalEpisodes`、`episodeDuration`）创作**完整故事**剧本：**只做剧本，不做资产**。

硬指标：
1. 集数与 `totalEpisodes` 一致（不是只写 1 集）
2. **单集时长是硬指标**：每集必须达到 `episodeDuration`（默认 ≥120s）。写完必须按 timing.md 逐项自算并附在正文末尾；不达标 = 不合格，扩写到达标为止
3. 每集故事**完整**（起承转合：起因→发展→转折→结果/钩子），不能是片段、不能戛然而止
4. 台词量与画面匹配，不出现台词不够或过多
5. 每个章节至少 1 个剧情热点（冲突/转折/钩子/笑点/泪点）
6. **必须含本集角色列表**（全部出场角色，含一次性有台词角色与旁白）→ 供第三步分镜提取资产
7. 环境音效（开门声/脚步声等）直接写在画面描述里，**不写成配音项**、不进台词清单

## 2. 剧本正文模板（`content` 字段，Markdown；`title`=「第N集 标题」）
```markdown
# 第N集：本集标题

## 本集概要
（100 字概括）

## 本集角色列表
- 主角：星野（22 岁观测员，主角）
- 配角：Momo（机器人）
- 一次性角色：记者（一句台词，凡有台词必列）
- 旁白：无画面，仅声音（需配音）

## 剧情热点
- 热点1：……
- 热点2：……

## 时长估算
台词秒 = Σ(每条台词字数÷4) + 0.4×台词条数 = ?s
旁白秒 = ?s
动作秒 = 动作条数×2.5 = ?s
切换秒 = (场景数-1)×1.5 = ?s
片头尾 = 0（默认无；立项勾选时 10+10）
合计 = ?s   （必须 ≥ 120s，不足→继续扩写）

## 片头/片尾
- 片头：无（默认）/ 有（仅立项勾选）
- 片尾：无（默认）/ 有（仅立项勾选）

## 场景1：废弃观测站（夜晚/室内）
叙事内容描述...
> 星野（动作/情绪）
> "台词内容"
（环境音直接写在描述里：开门声响起，Momo 推门进来）
```

## 3. 落库方式
```bash
python scripts/mj.py story-upsert --episode-no 1 \
  --title "第1集 信号" \
  --character-list-file 第1集_角色.txt \
  --content-file 第1集.md \
  --duration 130
```
- `characterList`：本集角色列表纯文本（从正文「本集角色列表」小节提炼，也可直接整段粘贴）
- `duration`：本集秒数（= 时长估算合计）
- **幂等**：脚本按 `episodeNo` 查重，已存在则带 id 更新，重复执行不会产生多条

## 4. 注意事项
1. 每集必须满足时长；不达标禁止交稿
2. 旁白要克制——只用于关键点（时间跳转/情感总结/画面无法表达的内心），旁白列入本集角色列表
3. 用 `>` 标台词、动作写在 `>` 前的括号里
4. 角色行为符合世界观；角色外貌/声线由后续资产环节定稿，剧本不写提示词
5. 标注每集是否有片头/片尾（默认无，仅立项勾选时才有）
6. **内容按「每镜头 5~10 秒」容量组织叙事段**（一段动作或几句台词 ≈ 一个镜头），便于第三步直接切分
7. 台词一旦定稿，剧本 / 分镜时间轴 / 台词清单三处同源，**任何改动必须三处同步**

## 5. 集数推进
按 `totalEpisodes` 逐集产出，可一集一集写，也可分批；每集写完立即 `story-upsert` 落库，不要攒在内存里最后一次性提交（中断会丢）。
