> 加载时机：流程第一步。目标产物 = `POST /api/projects` 一条项目记录 + `PUT /api/reviews/0` 立项评审。

# 第一步 立项（导演）

## 1. 开工必做
1. `python scripts/mj.py ensure` 确认 API 就绪；不通 = 阻塞，报告用户。
2. `project-list` 看是否已有同名项目（409 = 已存在，改用复用或换名）。
3. **逐项引导用户确认立项项**（见下表），不得擅自假设——这些字段决定全流程产物形态。
4. 确认后 `ensure-project` 建项目并自动 load 为当前项目。
5. `review-put --stage 立项 --decision 通过 --content-file 立项评审.md`。

## 2. 引导清单（必须输出给 user 逐项拍板）

### A. 必问项（无合理默认，缺了会返工）
| # | 立项项 | 选项/默认值 | API 字段 |
|---|---|---|---|
| 1 | **总集数** | 10~40 集（常见 20~25），禁止默认 1 集 | `totalEpisodes` |
| 2 | **画幅/目标平台** | 竖屏 9:16（抖音/快手/视频号，漫剧主流）=1；横屏 16:9=2；方 1:1=3 | `aspectRatio` / `targetPlatform` |
| 3 | **题材与受众** | 奇幻/都市/治愈/搞笑/悬疑… + 儿童向/成人向 | `genre` / `audience` |
| 4 | **美术风格** | 手绘水彩/日系动漫/简约扁平/写实… | `artStyle` |
| 5 | **配音语言** | 中文普通话（默认）/ 方言 / 其他 | `voiceLanguage` |
| 6 | **原创或改编** | 原创（默认）/ 改编（注明原著与授权） | `originalOrAdapted` |

### B. 建议确认项（有默认值，仍需用户拍板）
| # | 立项项 | 默认值 | API 字段 |
|---|---|---|---|
| 7 | BGM 风格 | 贴合题材情绪（治愈系=钢琴等） | `bgmStyle` |
| 8 | 交付物 | 第N集_原生版.mp4 + 第N集_配音版.mp4（均硬压简体中文字幕） | `deliverables` |
| 9 | 每集时长 / 片头片尾 | ≥120 秒；**片头片尾默认无** | `episodeDuration` / `hasOpeningEnding` |

### C. 项目名与故事
- **项目名**（`name`）：唯一、创建后不可改。用户未指定则由 Agent 从需求提炼并请用户确认。
- **故事名**（`storyName`）、**世界观一句话**（`worldview`）：Agent 基于题材+受众草拟，供用户确认。

### D. 引导方式（固定模板，每次立项必须照此输出）
```
# 立项引导（逐项等确认）
- 项目名：？   故事名：？   世界观一句话：？
| # | 立项项 | 选项/默认值 | 请确认 |
| 1 | 总集数 | 10~40（常见 20~25） | ？ |
| 2 | 画幅/平台 | 9:16 竖屏 / 16:9 横屏 / 1:1 | ？ |
| 3 | 题材与受众 | … | ？ |
| 4 | 美术风格 | … | ？ |
| 5 | 配音语言 | 中文普通话 | ？ |
| 6 | 原创/改编 | 原创 | ？ |
| 7 | BGM风格 | 贴合题材 | ？ |
| 8 | 交付物 | 双版成片+中文字幕 | ？ |
| 9 | 每集时长/片头片尾 | ≥120s / 无 | ？ |
```
用户说"随便/你定" → 按默认值定，并**写进项目字段**，不可事后漂移。

## 3. 美术风格锚点（全剧风格统一的根）
确认美术风格后翻译为**风格锚点块**，整体写入 `artStyle` 字段，后续所有生成统一引用，跨集不得换词：
```
artStyle = "日系动漫｜正向锚点：日本2D手绘动画电影美术风格，赛璐璐平涂上色，清晰深色描边线稿，扁平色块阴影，高饱和明快色彩，非写实、非照片、非3D渲染、非厚涂｜反向排雷：写实风格，真人，照片质感，3D渲染，CGI，厚涂油画，肌理笔触，体积感过强，电影实拍感"
```

## 4. 执行命令
```bash
# 单字段方式
python scripts/mj.py ensure-project --name "星海旅人" \
  --story-name "星海旅人" --worldview "废弃观测站收到来自星海的信号" \
  --total-episodes 20 --episode-duration 120 --aspect-ratio 1 \
  --target-platform "抖音" --genre "科幻治愈" --audience "全年龄" \
  --art-style "日系动漫｜正向锚点：…｜反向排雷：…" \
  --voice-language "中文普通话" --original-or-adapted "原创" \
  --bgm-style "治愈系钢琴" --has-opening-ending false --status 0

# 或一次性给完整 JSON（长文本用 --xxx-file）
python scripts/mj.py ensure-project --name "星海旅人" --data-file 立项.json
```
- 已存在同名项目 → 默认复用并 load（不覆盖）；要覆盖加 `--update-existing`。
- 建完必须 `project-current` 确认当前项目是自己刚建的那个。

## 5. 立项评审（stage=0）检查项
- [ ] 9 项立项字段均已确认且非空（总分集数、画幅、题材、风格、语言、原创改编、BGM、交付物、时长/片头尾）
- [ ] 美术风格锚点块已写入 `artStyle`
- [ ] 项目已 load 为当前项目
- [ ] 项目名无歧义、不与既有项目混淆
通过后 `review-put --stage 立项 --decision 通过`。
