> 加载时机：分镜落库后。目标：`review-put --stage 分镜`。
> **评审通过后必须请用户审核确认**，未获确认不得进入后续环节（本版本到分镜为止，确认后收尾）。

# 3.1 分镜评审（stage=2）

## 一、评审流程
```bash
python scripts/mj.py episode-list                      # 集
python scripts/mj.py shot-list --episode-id <id>       # 逐镜拉回核对
python scripts/mj.py review-put --stage 分镜 --decision 通过 --content-file 分镜评审.md
# 不通过：
python scripts/mj.py review-revision --stage 分镜 --issues-file 分镜问题.md
```
- 打回 → 修复后**全量重跑本文件全部规则**（不信任上轮"已修正"结论，不得只查被点名问题）
- 打回超 5 次自动升级 → 交用户决策

## 二、评审规则（逐项验证，不符即打回）
1. **每镜 11 项字段齐全**：`videoContent` / `firstFrameDesc` / `shotSize`+`camera` / `spatialPosition` / 资产引用 / `bgm` / `timecode` / `timeline` / `voiceConstraint` / `ambientSfx` / `duration`+`transition`。**任一镜缺任一项 → 直接 Revise**，不进后续项
2. **镜头时长 5~10 秒**（超 10 必拆、不足 5 必并，转场镜同此）；各镜 `duration` 之和 ≈ 本集 `duration`
3. **镜头编号连续**（shotNo 1..N），与 `shot-list` 返回一一对应，无重复无跳号
4. **全局 TC 连续**：`timecode` 逐镜顺延，末镜 TC_out = 本集总时长；与 `duration` 自洽
5. **时间轴全阶段无空白**：每镜含开场段 + 核心段 + 收尾段，无"无动作空白段"；台词时间段与精算秒数匹配（字数÷4+0.4，按情绪档）
6. **时间轴每段四要素齐全**：拍摄方式 / 画面内容 / 空间方位 / 环境氛围；开场段必查后两项
7. **时间轴精确性四点**：说话姿态明确 / 走位与时长物理自洽 / 收尾段逐人写清反应 / 入画与停步点明确
8. **动作时序三关**：① 关键动作（接电话/开门/转身/起立/拿起放下）必须独立成段，禁止状态 A 直接跳状态 B ② 先完成前置动作后开口（先接通再"喂"）③ 跨镜首尾衔接（上镜收尾动作与下镜开场承接，补注意力转移过渡）
9. **空间方位齐全且跨镜一致**：标志物位置 / 每人物相对站位 / 运动方向 / 不在场说明 / **人物面朝方向**；严禁人物位置横跳
10. **机位面×人物朝向自洽三关**：关1 朝向由机位面决定（禁止机位换面后人物仍死盯镜头）；关2 同机位连续镜头朝向一致，变化须有转身动作段；关3 旁观者视线与体态一致
11. **机位面左右三角核验四步**：读锚点 → 投影验算 → 比对分镜左右/中央 → 出画入画方向不与摆件冲突
12. **画面对象识别与空间方位精确性**：同类对象是否各自独立成资产并写清区分特征；间距可感知；动作指向具体对象；禁止"其中一个/旁边那个"
13. **同场景连续分镜已换位**（换面/换景别/换站位），无"同机位同景别纯切"
14. **一镜一视频**：无镜内多分镜/场景跳变/状态跳变
15. **运镜合理**：景别+机位+运镜三要素齐全；默认固定机位；禁静止乱晃、普通对话环绕、连续 3+ 运动镜头；特殊运镜 ≤ 6 处且注明动机
16. **转场标注齐全且可执行**，与情绪匹配
17. **BGM 逐镜标注**：每镜 `bgm` 为白名单曲目或"无"；`bgmRange` 落到镜头内秒点
18. **音频出现点表与逐镜一致**：`audioCueTable` 的镜头号+秒点+全局秒与 `timecode`、`bgmRange`、`sfxRange` 自洽；不得出现本集不存在的镜头号
19. **资产白名单齐全**：`assetWhitelist` 含全部有台词角色（含一次性、含旁白）+ 反复出现资产；镜头 `【资产引用】` 里的每个名字都能在白名单找到
20. **场景组合齐全性**：镜头引用的每个 `场景-状态-面` 都在 `assetWhitelist` 场景中；缺则补
21. **机位切换表齐全**：`cameraSwitchTable` 逐镜登记（场景区域/状态/朝向/景别/站位锚点/画面左/画面右），锚点角符合 θ±90° 换算
22. **台词清单合法**：`dialogueList` 为可解析 JSON；每个 line 含 `seq/shot/character/text/emotion/start_sec/duration_sec/end_sec`，**不含 file**；`episode` 与本集一致；文本与分镜 `timeline` 逐字一致；`start_sec/end_sec` 为全集累计秒且与全局 TC 自洽；`duration_sec = end - start`
23. **立项字段一致性**：画幅/美术风格/配音语言/片头片尾与项目字段相符
24. **真实产物**：字段为完整内容，非空占位；接口写不进去 = 阻塞，报告用户，不得放行
25. **AIGC 溯源块与水印零容忍**：扫描是否混入 `AIGC:` / Label / ContentProducer / ProduceID / ContentPropagator / PropagateID /「内容由AI生成，仅供参考」，发现即打回删除

## 三、内容审查（当前模型支持时执行）
- 视频内容符合剧本剧情走向；情绪/景别/机位与本镜意图匹配；镜头划分符合叙事节奏
- 转场与剧情情绪匹配
- 模型不支持内容审查时：不做内容审查，提醒用户自行审查，**不允许退化为数量/命名核对**

## 四、不一致处理
分镜内容/空间方位/运镜/时长任一与剧本或项目立项字段不一致 → 先提醒用户是否继续，不主动放行。

## 五、输出格式
```markdown
# 评审结论：分镜
结论：✅ Pass / ❌ Revise
覆盖：第N集，镜头 1~M
问题清单：
- RV-01: [问题描述]（期望 vs 实际）
- RV-02: ...
建议：打回分镜环节重写 / 升级用户
```

## 六、通过后
**必须把分镜产出提交用户审核确认**（列：集数、每集镜头数、总时长、白名单摘要，附 `shot-list` 抽样），用户确认后收尾并说明后续环节（资产/声线/音乐/音效/视频/配音/合成）待扩展。
