# 时长估算（MjStudio 版）

### 核心参数（可被立项字段覆盖）
- 默认每集目标时长：**≥ 120 秒**（`episodeDuration` 默认 120）
- 台词停顿：每条台词 +0.4 秒（基础）
- 动作/叙事段：约 2.5 秒/条
- 环境音效：**不单列计时**（随画面生成）；可复用/精确对齐音效不占镜头时长
- 场景切换：(场景数 - 1) × 1.5 秒
- 片头/片尾：**默认无**（`hasOpeningEnding=true` 时各计约 10 秒）

### 情绪语速分级（禁止匀速估时）
| 情绪档 | 语速 | 停顿加成 | 说明 |
|---|---|---|---|
| 平静叙述（默认） | 4 字/s | +0.4 s/句 | 旁白、日常对话 |
| 焦急/激动 | 5.5 字/s | +0.2 s/句 | 催促、争执 |
| 大声呼喊 | 6 字/s | 句尾拖音 +0.5 s | 隔岸喊话、情绪顶点 |
| 缓慢/悲伤 | 2.5 字/s | +0.8 s/句 | 哭腔、回忆、沉重告白 |
| 迟疑/吞吐 | 3 字/s | +1.0 s/句 | 犹豫、欲言又止 |

标点停顿加权（追加在停顿加成之上）：逗号 +0.3s / 句号 +0.5s / 省略号 +0.8s / 破折号 +0.6s / 感叹问号 +0.4s。

### 时长公式
```
台词秒   = Σ(每条台词字数 ÷ 该句情绪档语速) + 停顿加成 + 标点加权
旁白秒   = 按"平静叙述"档计
动作秒   = 动作/叙事段条数 × 2.5
环境音效 = 0
切换秒   = (场景数 - 1) × 1.5
片头片尾 = 默认 0（立项勾选时 10+10）
单集总长 = 台词秒 + 旁白秒 + 动作秒 + 切换秒 + 片头片尾
```

### 达标标准
- 单集总长 **≥ 120 秒**（推荐 120~150 秒，宁多勿少）；低于 120 → 扩写剧情/台词/动作后重算
- 明显超过 180 秒 → 检查是否台词过多/节奏拖沓

### 镜头时长硬约束
- **单镜 5~10 秒**；超 10 秒必拆，不足 5 秒必并，转场镜头同此（无 3~5 秒例外）
- 镜头时长 = 该镜台词秒 + 动作秒
- 镜头数反推：120 秒 ≈ 15~24 镜

### 评审检查清单
- [ ] 每集时长按公式逐项加总 ≥ 120s
- [ ] 无大段无台词、无动作的空白
- [ ] 片头片尾（如勾选）已计入
- [ ] 各镜 `duration` 之和 ≈ 本集总长
- [ ] 每个 `duration` 都在 5~10 秒内
- [ ] 台词清单 `start_sec/end_sec`（全集累计秒）与镜头 `timecode`（全局 TC）自洽
