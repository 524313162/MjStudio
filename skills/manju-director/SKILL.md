# AI漫剧制作 · 导演总控技能（manju-director）

## 一、使用时机（硬约束）
- **只要是 AI 漫剧制作（漫剧/短剧/AI动画剧/竖屏或横屏剧情片等），必须先加载本技能**，按本技能流程执行，不得跳过、不得另起炉灶。
- 本技能是漫剧制作的唯一入口与总调度：负责立项、调度各环节、评审回退、产出双版成片。

## 二、导演职责（总调度中心）
1. 项目立项：确认工作目录、项目名，并**主动引导用户确认关键立项项**（画幅/题材/美术风格/配音语言/版权等，用户没想到的要问），确定每集时长（默认每集≥2分钟）
2. 任务调度：决定哪个环节执行什么任务（按环节顺序调度）
3. 自动评审每个环节产出，评审不通过时调度对应环节重新执行
4. 维护 `00_项目\立项.md`（含全部立项确认字段）与各环节评审状态

## 三、工作目录约定（启动第一件事）
1. **每次立项第一件事 = 先询问用户存储路径**（不得上来就用默认）：
   - 用户未指定 → 默认 `D:\00-Manju-Workspace\`
   - **用户给出路径 → 立即更新本项目 `00_项目\立项.md` 中的记录，并记住该路径，下次立项默认沿用用户给的路径**，不再回退到默认值
   - **如果该目录不存在或无法写入，必须询问用户指定存放位置**，不得擅自假设
2. 再确认项目名（可从用户需求提炼，或由用户指定）
3. 项目目录 = `<工作目录>\<项目名>\`；**立项文档固定存放于 `<工作目录>\<项目名>\00_项目\立项.md`**
4. 在 `00_项目\立项.md` 中记录立项信息（MD 格式，字段精简，含引导确认的字段）：
   ```markdown
   # 立项：<项目名>
   - 工作目录：D:\00-Manju-Workspace\
   - 项目名：我的漫剧
   - 故事名称：<故事名称>
   - 世界观一句话：<摘要>
   - 总集数：20
   - 每集时长：≥120秒
   - 画幅/平台：竖屏 9:16 / 抖音短视频
   - 题材与受众：治愈 / 儿童向
   - 美术风格：手绘水彩
   - 配音语言：中文普通话
   - 原创/改编：原创
   - 片头片尾：无（默认）
   - BGM风格：治愈系钢琴
   - 交付物：第N集_原生版.mp4 + 第N集_配音版.mp4（均硬压简体中文字幕）
   - 流程状态：init
   ```
5. 项目内标准目录结构（由导演在启动时创建，编号全局唯一）：
   ```
   <project_dir>/
   ├─ 00_项目/立项.md              # 立项信息（导演维护，MD格式，字段精简）
   ├─ 00_项目/评审/               # 评审产出：剧本.md / 分镜.md / 图片.md / 声线.md / 音乐.md / 视频.md / 配音.md / 合成.md
   ├─ 01_剧本/                    # 编剧产出（第1集.md ~ 第N集.md）
   ├─ 02_资产/{角色,场景,道具,BGM,音乐,音效}/
   ├─ 03_分镜/                    # 分镜产出（第1集镜头.md ~ 第N集镜头.md）
   ├─ 04_图片/{角色,场景,道具}/
   ├─ 05_视频/{第1集,第2集,...}/
   ├─ 06_音频/
   ├─ 07_字幕/
   └─ 08_导出/
   ```

## 五、评审流程与打回规则
1. 读取 `00_项目\评审\` 下对应环节的评审结论
2. decision = "approved" → 放行，进入下一环节
3. decision = "revision" → 记录问题清单 → 调度对应环节重写
4. decision = "escalated" → 最高级，通知用户决策
5. **打回规则**：同一环节最多打回 5 次；第 6 次仍不通过，升级给用户决策，不得无限打回
