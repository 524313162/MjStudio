## 合成环节（合成，唯一混音方）
**职责**：漫剧最后一个制作环节，产出双版成片（**不请用户审核直接交付**）：
1. **原生版**：将视频环节（step-08）产出的镜头视频按顺序拼接为 `第N集_原生版.mp4`——**生成视频是什么样就什么样**（画面+环境音效），不混BGM/配音；相邻镜头对之间**直接硬切拼接**（转场衔接片段已取消，2026-09-07 用户决策）
2. **配音版**：以 step-09 配音环节产出的 `_配音.mp4` 分镜片段（原声全去、仅留换音色台词声，台词时间=ASR 实测）按序拼接为基础，混入 **BGM + step-07 可复用音效**，产出 `第N集_配音版.mp4`——环境音效已在画面内，配音已由 step-09 内嵌，本环节不再另混台词语音
3. **字幕**：从 `台词清单.json` 生成**简体中文字幕**，双版硬压（烧录）到视频画面，时间轴与配音对齐
4. **片头/片尾拼接**：仅当立项勾选时，将片头尾画面 + 片头尾曲拼到对应集首/集尾
5. **不做 M3U8/HTML 播放器、不做全片合并**

**镜头拼接（合并职责，合成只合并）**：
- 本环节**只负责合并拼接**，**不抽帧、不识别转场、不做平滑**——抽帧（`videoX_first.png` / `videoX_end.png`）、转场识别判断（`temp\转场判断.json`）、首尾帧平滑衔接片段生成（`videoN-(N+1).mp4`）**已全部取消**（2026-09-07 用户决策），本环节一律不参与
- 拼接时读 `05_视频\第N集\` 下实际文件：**相邻镜头对之间一律直接硬切相连**，无任何过渡片段
- 原生版与配音版的镜头拼接顺序一致，硬切位置一一对应

**真实合成（必须，取消一切模拟）**：所有产物必须真实生成——合成清单、台词/时间轴核对文件、**字幕SRT** → 真实写入；双版成片 → **ffmpeg 真实合成**；**禁止空文件占位**；评审以真实双版文件 + 合成清单/字幕SRT 为准。

**输出**：
```
07_字幕\第N集.srt                 # 先由台词清单生成简体中文字幕(时间轴=配音对齐)，硬压烧录到双版
08_导出\第N集_原生版.mp4           # 生成视频原样拼接(画面+环境音效，无BGM/配音)+硬压中文字幕
08_导出\第N集_配音版.mp4           # 原生版基础上混入BGM+配音+可复用音效(step-07)+硬压中文字幕的最终成片
```

**字幕规则（重要：必须）**：
- **字幕语言:简体中文**，文字严格取自 `台词清单.json`（对话+旁白），不增字不减字
- **台词清单 start_sec/end_sec 为全集累计秒**，直接当时间轴用，**无需再逐镜换算**
- 时间轴与配音对齐：每个 seq 用 `start_sec` ~ (下一个 seq 的 `start_sec` 或 本 seq 的 `end_sec`)为字幕显示区间；末句到该镜末尾
- 一句字幕一条，按 seq 顺序编号；间隔 <0.3s 的两条可合并显示
- **双版都要烧录字幕**，烧录后用播放器抽帧确认字幕在画面中
- ffmpeg 字幕烧录（硬压，Windows 下路径需转义冒号与反斜杠）：
  `ffmpeg -i "08_导出\第N集_原生版_无字.mp4" -vf "subtitles='07_字幕\\第N集.srt':force_style='FontName=Microsoft YaHei,FontSize=18,Outline=1'" -c:a copy "08_导出\第N集_原生版.mp4"`
  先合成无字幕中间文件，再烧录替换为双版成片；无中文字体时用系统自带微软雅黑
- **双版必须 ffmpeg 真实合成**：SRT 真实生成，压字幕后的 mp4 必须为真实可播放文件，禁止空文件占位

**混音规则（配音版，唯一混音方）**：
- 原生版画面**已含一次性随机环境音与原声口型音**；本环节混 BGM+step-07 可复用音效，**不混一次性随机环境音（已在画面内）**；台词语音由 step-09 配音环节以 `_配音.mp4` 分镜片段形式内嵌，本环节不另混
- **可复用/精确对齐音效混入（音效独立为 step-07 环节）**：读 `06_音频\音效\音效使用对照.json`（step-07 落盘的权威清单：镜头号+镜头内秒+全局秒，**必须存在且真实**，未生成清单视为音效环节未完成）+ 对应 wav/mp3 文件，按清单记录的全局秒用 ffmpeg `adelay` 精确触发（**无淡入淡出**，对齐画面动作点）；一次性随机环境音不在此列（已在画面内）
- **BGM 按分镜逐镜标注混入**：读分镜逐镜 BGM 标注 + 每个镜头时长，把对应 BGM 连续铺在**全片累计时间轴上**（镜头顺序×各自时长换算）；标"无"的镜头段 → **不播BGM(静音段)**；同一首BGM连续用于镜头1~3 → 在这3段累计时间内持续播放（整段铺底）；BGM 时长不足时从音轨截取；宁长勿短
- **BGM 按全局时间码精确落位（分镜升级为精确秒点，合成据此贴轨；以 step-06 落盘的清单为权威读取源）**：读 `06_音频\BGM\BGM使用对照.json`（step-06 落盘的权威清单：每首BGM逐镜 music_state + 全局秒 `TC_in~TC_out`，**必须存在且真实**，未生成清单视为音乐环节未完成）+ 对应 mp3，按清单的 `TC_in~TC_out`（全局秒）作为**淡入起点与淡出终点**，禁止只按镜头区间整段铺；静音段（"无"镜头或清单标注静音）→ 对应全局区间不播 BGM；同一首 BGM 分段使用时，按清单各段 TC 分别淡入淡出（默认淡入/淡出 0.5~1s，可微调）
- 配音按 `台词清单.json` 逐句对齐：每个 seq 读 `start_sec`（全集累计秒）将对应 wav 放到该时间点
- **台词时间轴实测定位（估算改实测，faster-whisper 实测锚定）**：台词 `start_sec` 不再依赖分镜/配音环节的估算校正，改为**合成环节用 faster-whisper 对成片音轨实测**——
  - **工具**：`D:\faster_whisper\transcribe.bat <音视频路径> [small|medium]`（独立 venv 调用：`D:\faster_whisper\venv\Scripts\python.exe D:\faster_whisper\transcribe_timestamps.py <音视频> [模型]`）；模型本地 `D:\faster_whisper\models\small`（中文默认 small，可换 medium），**离线可用**，无需联网下载
  - **时机**：混音前，先对**准合成版**（原生版画面+原声，或已混 BGM/音效但未放配音）提取音频，用 faster-whisper 转写（language=zh、vad_filter=True、min_silence_duration_ms=500），输出逐句真实 start/end
  - **映射回写**：faster-whisper 输出 `segments:[{start,end,text}]`（全集累计秒）→ 用其 start/end **校正 `台词清单.json` 每句的 `start_sec`**；**文本以台词清单为准（不增字不减字），时间以 ASR 实测为准**（与 faster-whisper 输出对齐）
  - 该实测值即为配音落点与字幕时间轴的唯一基准（step-09 配音环节已实测，合成环节沿用；替代旧的"配音环节按原声口型估算校正"）
- **原声处理（换音色归第9步配音环节）**：配音版不再在合成环节做"压低原声+叠入配音"——分镜片段原声已在 step-09 配音环节全去、仅留换音色台词声（`_配音.mp4`），合成环节直接拼接该片段即可，天然无双音/错位
  - 一句话封装命令示例（第X镜单句台词）：
    ```
    ffmpeg -i 镜头X.mp4 -i 镜头X_角色N_台词Y.wav -filter_complex \
      "[0:a]volume=enable='between(t,<start>,<start+dur>)':volume=0.1[orig]; \
       [1:a]adelay=<start*1000>|1000ms[vo]; \
       [orig][vo]amix=inputs=2:duration=first:dropout_transition=2[a]" \
      -map 0:v -map "[a]" 混音中间文件.mp4
    ```
    多句台词按各自时间窗叠加；无台词时段原声环境音保留
- 片头/片尾曲放在片头/片尾（与片头尾画面同步拼接，仅立项勾选时）
- 音量平衡：BGM 低于人声（默认 BGM -20dB，人声 0dB，可调）

**导出流程**：
1. **台词时间基准**：直接用 step-09 配音环节的 ASR 实测结果（已校正 `台词清单.json` 每句 `start_sec`，**文本以台词清单为准，时间以 ASR 实测为准**）；如台词清单未含实测值，再对 step-09 `_配音.mp4` 或准合成版用 faster-whisper 实测兜底（`D:\faster_whisper\transcribe.bat <音频> small`）
2. **字幕**：用校正后的 `台词清单.json` 生成 `07_字幕\第N集.srt`（简体中文，时间轴=配音对齐/ASR 实测）
3. **原生版**：把镜头视频 `videoX.mp4` 按分镜顺序 ffmpeg 拼接（**相邻镜头对之间一律直接硬切**，无衔接片段）→ 再烧录字幕 → `08_导出\第N集_原生版.mp4`（真实合成，禁止空文件）
4. **配音版**：用 step-09 产出的 `_配音.mp4` 分镜片段按序拼接（原声已去、仅留换音色台词声；**相邻片段直接硬切**，与原生版拼接顺序一致），按分镜逐镜BGM标注混入BGM（"无"镜头静音）+ step-07 可复用音效 → 烧录字幕 → `08_导出\第N集_配音版.mp4`（真实合成，禁止空文件）
5. **直接交付**：产出双版成片直接交付，**不提交用户审核**（原生版看画面，配音版看终效果；视频及后续环节不再审核直到流程结束）
6. **不做全片合并**：多集各自交付双版文件即可

**注意事项**：原生版 = 生成视频原样，不混任何音频（仅画面随带的一次性随机环境音），**但烧录中文字幕**；配音版 = 用 step-09 `_配音.mp4` 分镜片段拼接 + BGM + 可复用音效(step-07) + 中文字幕（**台词语音已由 step-09 内嵌、原声已去，本环节不再压低原声/叠入配音，避免双音与错位**）；step-07 可复用音效按分镜出现点表点触发混入（无淡入淡出）；字幕内容只来自台词清单（对话+旁白），**必须是简体中文**，不得用画面内已生成的任何文字；片头片尾默认无：仅 `立项.md` 勾选时才拼接片头尾并混入片头尾曲；台词清单.json 必须真实完整，start_sec 以 step-09 ASR 实测校正后的为准。
