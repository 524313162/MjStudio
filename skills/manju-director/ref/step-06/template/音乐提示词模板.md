# 音乐提示词模板（BGM/片头片尾曲，双文件两段式）

> 适用范围：音乐环节（step-06）为每首 BGM / 片头片尾曲编写独立提示词时使用，对齐图片资产提示词范式。
> 文件组织：每曲提示词 = **CN/EN 双文件**——`06_音频\BGM\<名称>_提示词_cn.md` + `<名称>_提示词_en.md`；音频类**无布局段**。
> 结构：cn = `# BGM 提示词：{BGM名}（背景音乐）cn` + 一级段 `# 正向提示词`（下挂 `## 风格` / `## 详细描述`）+ 一级段 `# 反向提示词`；en = `# BGM Prompt: {BGM名}（Background Music）en` + `## Positive Prompt`（`Style:` / `Detailed Description:`）+ `## Negative Prompt`。
> **不引入"版式（单独段）/基本信息/情绪层次（单独段）/参数化锚定（单独段）"等额外段**——参数化硬约束并入风格段，情绪层次时间轴并入详细描述段。

## 模板一：cn 文件（`<名称>_提示词_cn.md`）

```markdown
# BGM 提示词：{BGM名}（背景音乐）cn

## 正向提示词
风格：纯器乐{风格}单轨，仅输出乐器声，不混入人声/台词/歌词/说唱/人声哼唱/旁白；无杂音无爆音削波，动态规整自然；高保真 48kHz 24bit，母带保留完整情绪起伏；{节奏 BPM {X}，回锚资产文件 BPM 参数化锚点}；{时长 {歌曲式 2~4 分钟}，硬约束落 --duration}；{电平 {X} LUFS}；{循环性：整曲完整/可循环截段}
详细描述：{用途情绪（温馨日常/紧张追逐/悲伤，来自剧本情绪走向）+ 风格乐器清单 + 情绪层次时间轴（如：0:00~0:40 暗流铺垫 → 0:40~1:10 第一次小高潮 Riser 上扬 → 1:10~1:40 回落蓄力 → 1:40~2:20 主高潮爆燃 → 2:20~2:50 收束余韵，供合成"情绪到位时精准取片段"）的完整中文描述}

## 反向提示词
{排除项：过度欢快/杂音/人声混入/失真空旷…}
```

## 模板二：en 文件（`<名称>_提示词_en.md`）

```markdown
# BGM Prompt: {BGM名}（Background Music）en

## Positive Prompt
Style: {与中文风格段对应的英文}
Detailed Description: {与中文详细描述段对应的英文，供 music_gen.py --prompt 提交}

## Negative Prompt
{与中文反向对应的英文，供 music_gen.py --negative 提交}
```

## 编写要求

- **对应资产**：提示词文件开头注明 `对应资产：02_资产\BGM\{资产文件}.md`；**参考音频硬锚**：资产文件「参数化锚点」有参考音频则写路径，无则"以资产文件「用途/风格+参数化锚点」为准"
- **应用判定来自剧本**：读 01_剧本 + 03_分镜，梳理全片情绪起伏曲线，判定"哪里响哪里歇"——情绪推进会/爆发爽点在 → 音乐推进；压抑/死寂/悬念关键点 → 抽离或骤停
- **必须描述高潮起伏点及所在时间轴位置**：提示词中明确写出该曲的情绪层次结构（如：0:00~0:40 暗流铺垫 → 0:40~1:10 第一次小高潮 Riser 上扬 → 1:10~1:40 回落蓄力 → 1:40~2:20 主高潮爆燃 → 2:20~2:50 收束余韵），供合成阶段"情绪到位时精准取片段"；时长取正常歌曲长度（约 2~4 分钟）
- 用途情绪（温馨日常/紧张追逐/悲伤）→ 明确情绪目标；风格与乐器（钢琴/弦乐/电子/民族乐器）；节奏（慢板/中板/快板，含 BPM）；**反向提示词**：要避免的内容（过度欢快/杂音/人声混入/失真空旷等）；全剧 BGM 风格必须统一
- cn/en 两文件段落结构一一对应，内容语义一致（cn 中文 / en 英文）
