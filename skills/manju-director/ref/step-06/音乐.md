## 音乐环节（音乐制作）
**职责**：根据**剧本情绪走向**与资产白名单中的 BGM 资产，制作：
- 背景音乐（BGM）—— 对应 `02_资产\BGM\BGMN.md`（**歌曲式情绪母带**：按剧本判定情绪需求，一首规整长度的完整曲子）
- 片头曲/片尾曲（**仅当立项.md 勾选片头片尾时**）—— 对应 `02_资产\音乐\片头或片尾曲.md`

**职责边界**：本环节**不做环境音效**（一次性随机环境音开门/脚步等由视频环节随画面生成）；只做**背景音乐 BGM（情绪氛围）** + 片头尾曲。**可复用/精确对齐音效**（鸟鸣/风声/水花/特效音）由 **step-07 音效环节**用 `09.STABLE-BGM.json` 切 SFX 档生成（见 `ref\step-07\音效.md`），本环节不做（音效独立为 step-07 环节）。

**环节位置**：音乐环节在**声线环节之后、音效环节之前**执行（生成资产图片→声线取声→生成BGM→**音效**→视频→配音→合成）；先有分镜情绪与台词，再判定 BGM 情绪使用段。

**输出**：
- `06_音频\BGM\BGMN.mp3`（**歌曲式母带**：正常歌曲长度，约 2~4 分钟规整曲式，非"覆盖镜头累计时长"的加长铺底）——母带保留完整情绪起伏，合成阶段按"情绪到位点"精准截取片段填充
- `06_音频\音乐\片头曲.mp3` / `片尾曲.mp3`（仅立项勾选时）
- **BGM使用对照文件（真实）**：`06_音频\BGM\BGM使用对照.json`，记录每首BGM按**剧本情绪段**判定在哪些镜头使用（逐镜标注 music_state：ON/OFF/LOW/CUT 与情绪处理；**每条必须带全局时间码 TC_in~TC_out（读分镜"本集音频出现点表"的精确起播/停止秒点）**；关键静默点如录音致命一击、短信惊雷须消声；未被使用的段落=静音）

**音乐提示词编写（独立产出，对齐图片资产提示词范式，CN/EN 双文件两段式）**：按资产文件 用途/风格 编写**独立音乐提示词文件 = CN/EN 双文件两段式**（`06_音频\BGM\<名称>_提示词_cn.md` + `<名称>_提示词_en.md`；音频类**无布局段**）。**完整模板（cn/en 结构、各段写法、编写要求）见 `ref\step-06\template\音乐提示词模板.md`**，本环节不内嵌重复模板。

```
- **对应资产**：提示词文件开头注明 `对应资产：02_资产\BGM\{资产文件}.md`；**参考音频硬锚**：资产文件「参数化锚点」有参考音频则写路径，无则"以资产文件「用途/风格+参数化锚点」为准"
- **应用判定来自剧本**：读 01_剧本 + 03_分镜，梳理全片情绪起伏曲线，判定"哪里响哪里歇"——情绪推进会/爆发爽点在 → 音乐推进；压抑/死寂/悬念关键点 → 抽离或骤停
- **必须描述高潮起伏点及所在时间轴位置**：提示词中明确写出该曲的情绪层次结构（如：0:00~0:40 暗流铺垫 → 0:40~1:10 第一次小高潮 Riser 上扬 → 1:10~1:40 回落蓄力 → 1:40~2:20 主高潮爆燃 → 2:20~2:50 收束余韵），供合成阶段"情绪到位时精准取片段"；时长取正常歌曲长度（约 2~4 分钟）
- 用途情绪（温馨日常/紧张追逐/悲伤）→ 明确情绪目标；风格与乐器（钢琴/弦乐/电子/民族乐器）；节奏（慢板/中板/快板，含 BPM）；**反向提示词**：要避免的内容（过度欢快/杂音/人声混入/失真空旷等）；全剧 BGM 风格必须统一

**生成流程（本技能统一接口，真实调用）**：读取剧本与分镜 → 判定每首BGM的情绪使用段与高潮时间轴 → 确定每首BGM时长（歌曲式 2~4 分钟）→ 编写独立音乐提示词文件（含高潮起伏点时间轴描述）→ **必须调用统一接口脚本（禁止临场写接口代码）**：BGM用 `09.STABLE-BGM.json`、片头尾曲用 `08.ACE-MUSIC-音乐生成.json`，节点映射由封装脚本 `ref\step-06\scripts\music_gen.py`（内联提交引擎）内部处理，提交取回真实音频。禁止模拟/空文件占位；BGM使用对照文件必须真实填写。

**标准提交命令（music_gen.py 唯一入口）**：
```
REM BGM 纯器乐（09号）
python ref\step-06\scripts\music_gen.py --type bgm --name <BGM名> --prompt "<短描述>" --duration <秒> [--negative "<反向词>"] [--seed N] [--out-dir "06_音频\BGM"] [--dry-run]

REM 歌曲/片头片尾曲（08号）
python ref\step-06\scripts\music_gen.py --type song --name <歌名> --prompt "<tags描述>" --lyrics "<歌词>" --duration <秒> --bpm 120 --keyscale "D major" --language zh [--seed N] [--out-dir "06_音频\音乐"] [--dry-run]
```
- 脚本自动填节点 → 写临时 workflow JSON → 内联提交引擎提交/轮询 → 从 output 目录源件 Copy-Item 取回（**严禁 8188/view 下载通道，带 AI 角标水印**）→ 复制后核对字节数一致 → 落盘 `--out-dir`
- 退出码：0=成功、2=任务失败、3=超时、4=参数/模板/取回错误；最后一行输出 JSON 结果；`--dry-run` 只打印构造的 workflow 关键节点，不真实提交
- **档位铁律**：09 号 52:43 CustomCombo 默认 `choice=Music`（BGM 纯器乐）；`SFX / One-shot` 档用于生成**音效**，不属本音乐环节（归 step-07 音效环节，见 ref\step-07\音效.md）——音乐环节一律保持 Music 档

**注意事项**：BGM 是歌曲式母带，不必整集铺满；按剧本情绪判定使用段，音乐只在情绪需要的镜头出现；母带保留完整情绪起伏，合成阶段按高潮时间轴精准截取片段，未使用的段落静音；风格与世界观美术风格统一；**未在任何镜头使用的BGM不制作**。
