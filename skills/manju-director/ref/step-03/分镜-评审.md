> 加载时机：分镜环节产出后执行评审时。评审规则不符即打回。

> **用户审核**：分镜评审通过后，**必须将分镜产出提交用户审核确认**，用户确认后才进入下一环节（资产图片）。未获用户确认不得自动放行。

## 一、评审流程与打回规则
1. 读取 `00_项目\评审\` 下对应环节的评审结论
2. decision = "approved" → 放行，进入下一环节
3. decision = "revision" → 记录问题清单 → 调度对应环节重写
4. decision = "escalated" → 最高级，通知用户决策
5. **打回规则**：同一环节最多打回 5 次；第 6 次仍不通过，升级给用户决策，不得无限打回

## 二、评审规则（必须逐项验证，不符即打回）
1. **每镜 11 项字段齐全**：视频内容 + 首帧画面描述 + 运镜 + 空间方位 + 资产 + BGM + 镜头时间轴 + 发声约束 + 环境音效 + 时长 + 转场（生成模式不标注，默认15号多图参考系列）；**任何一镜缺任何一项 → 结论直接 Revise**，不进入后续评审
2. **镜头时间轴全阶段且无空白**：每镜有"镜头时间轴"字段，按时间段切分（开头状态段+台词/核心动作段+收尾段）；**每段时间都有明确动作/表情内容，禁止"无动作空白段/画面空转"**；台词时间段与精算秒数匹配（字数÷4+0.4）；镜头首尾均有内容（违者 Revise）
3. **台词秒数精算**：每句台词标的时间段≈精算秒数（字数÷4+0.4），如18字≈4.9s；台词时间段+前后动作段=镜头总时长（重叠/超出→Revise）
4. **空间方位标注齐全且跨镜一致**：每镜必须有"空间方位"字段（①场景标志物位置②每人物相对标志物站位③人物运动方向④不在场人物说明）；同一场景跨镜头的空间关系必须一致；严禁人物位置横跳/从中心冒出来又离开/站位矛盾（违者 Revise）
4.1 **画面对象识别与空间方位精确性（通用方法论，适用于任何故事，防止对象混淆）**：逐镜核「画面对象识别与空间方位精确性」通用框架——①独立资产提取：凡满足"参与剧情动作/观众需分辨同类相似对象/需跨镜一致/与角色空间交互"任一条的对象，必须独立成资产文件并写清区分特征（禁止合并成笼统道具）；②空间方位四要素：参照系明确+间距可感知+动作指向落到具体对象+下游可无歧义执行；只写"画面中有X个相似对象，其中一个…"式笼统描述、动作对象不明、不给距离参照 → Revise。约束必须留在分镜源头（而非后置到通用视频逻辑文档/脚本），发现后置 → 打回分镜补齐
4.2 **机位面×人物朝向自洽性（专项必查，防止同场景换机位时人物朝向逻辑错误）**：逐镜核"机位面×人物朝向自洽性"三关——
   - **关1 人物相对镜头的朝向由机位面决定**：`镜头朝X` = 机位在X对面、向X拍摄；人物站位与面朝方向（以场景标志物为锚点，相对世界固定）不变时，换机位面 = 人物相对镜头的朝向自动翻转：人物面朝X方向 → 背对镜头（背影）；人物面朝机位方向 → 正对镜头（正脸）；垂直 → 侧对镜头。写"正脸/侧脸/背影"必须与机位面、人物面朝方向三者物理自洽；**禁止机位换面后人物仍死盯镜头**（违者 Revise）
   - **关2 同机位连续镜头朝向一致**：同一场景同一机位面的连续镜头，人物朝向必须一致；中途变化必须有明确"转身/别过脸去/侧过身"动作段交代；禁止空间方位写"背对/侧对"而时间轴无转身动作 → Revise
   - **关3 旁观者视线与人物体态一致**：站在某方位（如北墙门口）的旁观者看到的必须是人物实际体态：人物面朝东时，北侧旁观者看到侧影（非背影）、东侧看到正脸、西侧看到背影；写"背影/侧影/正脸"须与旁观者方位、人物面朝方向核对（违者 Revise）
   - 正反例：
     - 正确：镜头1朝东（机位在西）人物面朝东墙=背影；镜头2朝西（机位在东，反打）人物仍面朝东=正对机位=正脸——机位换面、人物不动、一背一正，正反打成立。
     - 错误A：镜头1朝东写人物正对镜头，镜头2朝西仍写人物正对镜头（机位换了人物还死盯镜头）。
     - 错误B：镜头1朝东写人物面朝东（正对机位），镜头2同机位朝东却写"人物背对镜头"，且无转身动作交代。
5. **台词时间轴标注齐全**：每句有台词的台词都标注 `[start_sec~end_sec]`（按 `本技能 timing.md` 累加，start=上一句end+0.4s；末句end≤镜头时长），无台词镜头标"无"——供视频口型/配音/字幕对齐唯一源，台词文本不得被后续环节增删
5.1 **台词清单模板**：必须同步产出 `03_分镜\第N集台词.json`（分镜环节与分镜同步产出）。校验：①**必须为合法 JSON 格式**（可直接解析）；②**字段不可少**，每个 line 必须含 seq/shot/character/text/emotion/start_sec/duration_sec/end_sec 全部字段，**不得含 file 字段**；③**必须符合模板结构** `{"episode":N,"lines":[...]}`，episode 与本集一致；④台词文本与分镜逐句对应（不增删改），start_sec/end_sec 为全集累计秒且与分镜台词时间轴一致、duration_sec=end-start。缺任一字段 / 格式非法 / 与分镜不一致 → Revise
6. **时间轴精确可执行**：逐镜核"镜头时间轴精确性规则"四点——①每句台词写明说话时机与姿态（边走边说/走停再说/站定说/边做边说，从几秒开口、几秒收住话音）②人物位移与时长自洽（走位距离在该时长内物理可行，写明入画→路径→何时停步→停在距对方多远；禁止"镜头下方入画走到画面深处人面前"这种走不完的距离）③收尾段逐人写清在场角色表情状态（被挑衅/对峙方必须有明确神态动作描写，禁止"两人纵深对峙/同框对峙"空洞描述）④说话人入画时刻与停步衔接明确；任何一镜含糊（只说"说台词"不交代姿态/走位物理不可行/收尾无对方反应）→ Revise
6.1 **动作时序与跨镜连贯性（专项必查，带正反例）**：逐镜核"动作可执行性"三关——
   - **关1 关键动作必须独立成段**：凡镜头内有"接电话/挂电话/开门/转身/起立/落座/拿起放下某物"等关键动作，必须单独占用一个时间段完整描写（含动作触发→执行→完成），**禁止从"状态A"直接跳到"状态B"**（如开场只写"盯着手机"，下一段却已"开口说话"——中间"伸手拿起→看号码→犹豫→接通"全部缺失 → Revise）。
   - **关2 动作-台词时序物理自洽**：先完成前置动作、后开口说话。例：必须**先接起电话、把手机凑到耳边，才开口"喂"**；禁止"边说边拿起手机凑到耳边"（开口瞬间尚未接通，物理不可能）→ Revise。
   - **关3 跨镜首尾衔接**：上一镜收尾动作与下一镜开场动作必须衔接成连续行为。上镜在"盖纸箱盖"，下镜"手机震动"，中间必须补"动作顿住→目光被响声吸引→移向手机"的过渡，禁止开场直接进入与上镜收尾无关的新状态 → Revise。
   - 错误示例（违反关1/关2/关3，禁止）：
     ```
     - [0.0~1.5s] 开场:近景+平视+固定机位,桌上的旧手机疯狂震动,屏幕亮起陌生号码,陈默盯着手机屏幕,眉头紧锁;无台词
     - [1.5~8.7s] 台词段:近景+平视+固定机位,陈默[1.5~8.7]说"喂……张哥,宽限几天……"(边说边拿起手机凑到耳边,声音迟疑发颤,约8.7s收住话音)
     - [8.7~10.0s] 收尾:近景+平视+固定机位,他听完电话里的怒骂,攥紧手机,指节发白
     ```
     问题：开场只"盯着"未接起→台词段却已开口说话（接电话动作缺失）；"边说边拿手机"时序倒置（应先接通再"喂"）；上镜盖纸箱、本镜手机突震（无注意力转移过渡）。
   - 正确示例（合规）：
     ```
     - [0.0~1.5s] 开场:近景+平视+固定机位,陈默盖纸箱的动作顿住,目光被桌面震响的手机吸引,眉头微皱;手机在桌面震动,屏幕亮起陌生号码;无台词
     - [1.5~3.0s] 动作段:近景+平视+固定机位,他伸手拿起手机,看到陌生号码,指尖悬停,眼神迟疑,犹豫是否接听
     - [3.0~4.0s] 动作段:近景+平视+固定机位,他深吸一口气,按下接听,把手机缓缓凑到耳边
     - [4.0~8.7s] 台词段:近景+平视+固定机位,陈默[4.0~8.7]说"喂……张哥,宽限几天,我……我真的一分都拿不出了……"(接起后开口,声音迟疑发颤,说到"宽限几天"时喉结滚动,约8.7s收住话音)
     - [8.7~10.0s] 收尾:近景+平视+固定机位,他听完电话里的怒骂,攥紧手机,指节发白,眼眶泛红,嘴唇紧抿
     ```
     要点：接电话动作独立成段、先接通后开口、开场承接上镜盖箱动作并补"顿住+目光转移"。
7. **时间轴每段四要素齐全**：逐段核时间轴**每个时间段**（开场/台词/动作/收尾）必须同时含①拍摄方式（景别+机位+运镜）②画面内容（谁在哪做什么/什么表情）③空间方位（角色在画面哪边/距对方多远）④环境氛围（光线/环境状态）；**开场段必查③④**（与场景资产一致性锁定对齐）；任一时间段缺任一要素（如只写"谁凑近谁"不交代拍摄方式/方位/氛围）→ Revise
8. **运镜标注齐全且合理**：每镜必须有"景别+机位+运镜"三要素标注；**默认固定机位**；人物移动→跟镜头/聚焦情绪→推镜头/段落收尾→拉镜头/视线转移→摇镜头/情绪峰值名场面→环绕；**禁**人物静止乱晃、普通对话环绕、连续3个及以上运动镜头、推完立刻拉；特殊运镜每集≤6处且注明动机（违者 Revise）
9. **转场标注齐全且可执行**：转场方式可执行；纯转场镜头有明确内容
10. **分镜不标注生成模式**：所有镜头默认走 15.MinimaxH3 多图参考{N:02d}.json（纯图像槽 media_1~N，无音频参考槽）；**不再强制首帧图**；旧多合一/10.x/12.1/12.2/14尾帧全部废弃
11. **引用资产均能在 `02_资产\` 中找到**
12. **白名单资产齐全**：反复出现资产 + **所有有台词角色均入白名单并已提取**（凡有台词角色，哪怕一次性出场、一句台词如记者/群众个体，都必须提取资产；漏提→打回补提；仅无台词群像可不入白名单）
13. **镜头总时长 ≈ 剧本时长**（≥2分钟）
14. **每个镜头时长在 5~10 秒内**（超10s必拆、不足5s必并；转场镜头同样须5~10秒，无3~5秒例外；转场嵌在镜头转场内实现，不单设超短镜头）
15. **镜头编号连续**（镜头1、镜头2…），与视频Agent产出 `镜头X.mp4` 一一对应
16. **逐镜BGM标注**：镜头语言/景别/逐镜BGM（每镜曲目或"无"，曲目必须在本集白名单BGM中）齐全
17. **BGM/音效落位**：分镜头部有"音频使用位置总表"，BGM"使用位置"写 `镜头X 0.0s - 镜头Y 结尾`（**无全局TC**），嵌入方式标注 **ffmpeg afade 淡入淡出**；音效"使用位置"写点触发式 `镜头X 第Y秒触发`（精确对齐，**无淡入淡出**）；所有音频资产落位不得超出本集实际镜头范围（不得出现本集不存在的镜头号）、与逐镜时长自洽、与分镜各镜 BGM 标注一一对应（违者 Revise）
18. **立项字段一致性**：每个环节的产出都必须符合 `00_项目\立项.md` 中导演引导确认的立项项（美术风格/画幅/配音语言/片头片尾等），不符合视为 Revise
19. **真实产物判定**：所有产物必须为真实生成文件，空文件/占位文件一律视为未完成 → Revise，不得放行；接口未联调导致无法真实产出时，该环节标记"阻塞"，报告导演与用户，不得以空文件充数
20. **AIGC溯源块与水印零容忍**：评审必须扫描并清理 AIGC 溯源块（`AIGC:` / Label / ContentProducer / ProduceID / ReservedCode1 / ContentPropagator / PropagateID / ReservedCode2）与文字水印（内容由AI生成，仅供参考）。发现即打回要求删除，不得放行——带 AIGC 块的产物无法通过抖音平台审核。全流程各环节评审必查。
21. **引用一致性**：任何环节不得擅自改写资产文件中的外貌/声线

## 三、内容审查（仅当前模型支持时执行）
- **镜头合理性**：视频内容符合剧本剧情走向（谁在哪做什么），情绪/景别/机位与本镜意图匹配；**镜头划分符合叙事节奏**
- **转场合理性**：每个镜头转场方式与剧情情绪匹配（温馨→叠化/淡入、紧张→硬切、回忆→闪白/柔化）
- 模型不支持内容审查时：不做内容审查，提醒用户自行审查；**不允许退化为数量/命名核对**

## 四、不一致处理
分镜内容/空间方位/运镜/时长任一与剧本或 `立项.md` 不一致 → 先提醒用户是否继续，不主动继续/放行
