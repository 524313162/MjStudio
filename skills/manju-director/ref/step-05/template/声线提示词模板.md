# 声线提示词模板（角色专属声线）

> 适用范围：声线环节（step-05）为每个出场且需配音的角色配置专属声线时，产出该角色的声线提示词。
> 文件组织：每角色 `_cn.md`（中文，供审核）+ `_en.md`（英文，提交）双文件，与角色图片提示词模板同构，**音频类无布局段**。
> 严禁沿用单文件 BGM 提示词模板写声线提示词。

## 文件命名

- `<角色名>_声线提示词_cn.md`（中文，供审核）
- `<角色名>_声线提示词_en.md`（英文，提交）

## 模板一：cn 文件（`<角色名>_声线提示词_cn.md`）

```markdown
# 声线提示词：{角色名}（角色专属声线）cn
## 正向提示词
风格：{音质参数硬约束}
详细描述：{声音特质}
## 反向提示词
{声音负面约束清单}
```

各段填写要求：
- **风格**：音质参数硬约束，如采样率（高保真16kHz以上）、单一声源、声像居中、动态自然、录制空间干净无混响等
- **详细描述**：声音特质，含**性别/音色/气质/语速**，可补充语气、情绪表达、贴合的人设（如"职场老实同事，怯懦温顺"）
- **反向提示词**：声音负面约束清单，如低沉沙哑、尖亮、大声、官腔、女性声/童声（按角色性别排除）、结巴、含混、混响、背景噪音、第二人声、歌唱式等

## 模板二：en 文件（`<角色名>_声线提示词_en.md`）

```markdown
# Voice Prompt: {角色名} (Character Voice) en
## Positive Prompt
Style: {音质参数硬约束，与 cn 风格段对应}
Detailed Description: {声音特质，与 cn 详细描述段对应}
## Negative Prompt
{声音负面约束清单，与 cn 反向提示词对应}
```

## 一致性要求

- cn/en 两文件段落结构一一对应，内容语义一致（cn 中文 / en 英文）
- 声线提示词的"详细描述"必须引用 `02_资产\角色\<角色名>.md` 中该角色的声线特征，不得凭空编造
- 固定段落（`## 风格` / `## 详细描述` / `## 反向提示词`）名称跨角色统一，仅内容按角色差异化
- 禁止引入版式（单独段）/基本信息/情绪层次（单独段）/参数化锚定（单独段）等额外段
