## 声线环节（声线·仅取声线种子）

**职责**：声线环节在**资产图片产出后、音乐之前**执行（标准顺序：资产图片 → 声线 → 音乐 → 视频）。本环节**不对台词逐句配音**（逐句配音归新增的第9步配音环节，见 ref\step-09\配音.md），仅配置各出场角色专属**声线种子**（视频生成取声 + step-09 配音环节换音色目标）；台词清单由分镜环节产出（`03_分镜\第N集台词.json`，见 ref\step-03\分镜.md）。

**核心流程（单步）**：
1. **为所有出场且需配音的角色配置专属声线种子**（视频生成取声）：
   - 用 **13.MiniMaxH3 文生视频.json** 生成该角色**念自我介绍台词**的短视频
   - **ffmpeg 从该视频提取音频** 作为该角色的声线种子，全剧复用
   - 台词固定为："我是XX，我的名字叫xx，很高兴认识你"（XX = 角色名），**duration 由 Agent 适当控制**（默认 5 秒）

**配置角色专属声线（视频生成取声）**：
- 出场且需配音的**每个角色都要有一个专属声线**（含旁白），**不配齐不进入后续环节**
- 用 13 号文生视频工作流（纯文本提示词，无图参考）生成角色自我介绍短视频：
  - 提示词**必须描述该角色声音特质**（性别/音色/气质/语速），确保生成的声音贴合角色人设
  - 台词固定模板："我是XX，我的名字叫xx，很高兴认识你"
  - **duration 由 Agent 适当控制**：默认 5 秒（台词约 4.5 秒朗读 + 首尾留白）；旁白/语速慢的角色可适当延长到 6~7 秒
- 从该视频提取音频作为种子声线：`ffmpeg -i "<角色名>_自我介绍.mp4" -vn -ac 1 -ar 16000 "<角色名>_种子.wav"`
- 提取后必须**试听抽查**确认只含该角色声音（若混入他人声，缩短截取或重生成）
- **每角色一次全剧复用**（存放 `06_音频\声线\<角色名>_种子.wav` + `<角色名>_声线.json` + `<角色名>_自我介绍.mp4`）
- 旁白/无立绘角色：与其它角色同法（提示词描述旁白声线特质），**不做基础音兜底**

**输出**：
- 角色种子声线：`06_音频\声线\<角色名>_种子.wav` + `<角色名>_声线.json`（音色特征、来源:视频生成取声、种子路径、来源视频、复用标记）+ `<角色名>_自我介绍.mp4`（取声源视频，保留备查）。**全部出场角色的种子必须配齐**
- **不产出**：各集台词语音 wav、`06_音频\第N集\台词清单.json`（台词清单由分镜环节产出 `03_分镜\第N集台词.json`，见 ref\step-03\分镜.md）

**台词清单说明**：
- 台词清单 = `03_分镜\第N集台词.json`，在**分镜环节**与 `03_分镜\第N集镜头.md` 同步产出（字段：seq/shot/character/text/emotion/start_sec/duration_sec/end_sec；`file` 字段为配音环节换音色台词 wav 的落盘名，如 `镜头2_小墨_台词2.wav`，2026-09-04 用户新需求示例）
- 台词文本/角色/情绪/镜头号**逐字取自分镜镜头时间轴标注**，不得增删改；`start_sec`/`end_sec` = **全集累计秒**（由分镜全局时间码 TC 换算，分镜估算值，非最终依据）
- step-09 配音环节以实测（faster-whisper）为准定位台词并换音色；step-10 合成环节以此清单生成字幕、混音

**种子声线取声规则**：
0. **AIGC 声明校验（生成端硬拦截）**：`voice_seed_gen.py --extract` 提取种子 wav 后**默认自动**调用 `aigc_scan.py`（本地 faster-whisper ASR，内存转写不落盘）校验音频内无「本音频由人工智能生成」等 AIGC 声明语音；命中即**删除不合格 wav 并报错要求重新取声**（`--skip-asr-check` 可跳过，仅调试用，正常流程禁用）。评审端同用 `aigc_scan.py` 复核。
1. **时机**：声线在资产图片产出后执行
2. **范围**：**全部出场且需配音的角色逐一配置专属声线**（每个角色、包括旁白）；逐个角色完成，配齐后进入后续环节
3. **取声（核心，防止混入他人声）**：用 **13.MiniMaxH3 文生视频.json** 生成角色独白念自我介绍台词短视频（话术示例："我是XXX，我的名字叫XXX，很高兴认识你"，单角色、无对白）。**提示词必须描述该角色声音特质**（性别/音色/气质/语速）。**严禁**在对白画面中取声。
4. **提取**：ffmpeg 从取声视频提取音频作为种子声线（整段就是该角色声音则全取，时长通常5~10秒）
5. **每角色一次**：若种子已存在 → 直接复用，不重复生成
6. **旁白/无原声角色**：统一视频生成取声法（提示词描述旁白声线特质，用讲述者/空镜类画面承载声音）
7. **配齐校验**：核对 `声线\` 下种子覆盖全部出场角色（含旁白）；缺任一角色 → 补种子后再进入后续环节

**注意事项**：所有出场且需配音角色必须先配齐专属声线，**不配齐不进入后续环节**；种子声线来自**角色自我介绍视频**（独白，避免混入他人声）；**同一角色跨集必须用同一种子声线**；**种子声线只配一次全剧复用**（第2集起直接读取声线档案，不再重新生成取声视频）；仅无台词群像不需配音；**环境音效不配音**。

- **声线提示词格式（必须按模板 `ref\step-05\template\声线提示词模板.md` 产出双文件两段式）**：声线提示词与角色提示词同构——`<角色名>_声线提示词_cn.md`（中文，供审核）+ `<角色名>_声线提示词_en.md`（英文，提交）。完整模板（含标题行、风格/详细描述/反向各段写法、en 对应结构）见 **`ref\step-05\template\声线提示词模板.md`**。**严禁沿用单文件 BGM 提示词模板**写声线提示词。
