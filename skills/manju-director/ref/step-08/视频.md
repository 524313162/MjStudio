# 视频环节（step_08 · 08-1 视频，视频生成）

## 1. 环节职责与边界

### 1.1 职责
按分镜的镜头内容、人物、场景、道具信息，用 **15.MinimaxH3 多图参考01~20（按参考图数量 N 自动选 `15.MinimaxH3 多图参考{N:02d}.json`，N≤20）** 逐镜生成视频，提交细节全部由 `ref\step-08\scripts\video_gen.py` 封装，正常出片一律走脚本。

参考图排定规则：**media_1 永远是本镜状态+朝向匹配的场景组合图（`04_图片\场景\<场景>-<状态>-<面>.jpg`，如 `小木家-白天-镜头朝东.jpg` / `池塘-夜晚-镜头朝北.jpg`），media_2~N 依次为角色（每角色独立单图）/场景/道具参考图，全部作全能从参考**。

### 1.2 视频生成规则（铁律）
- **视频严格按分镜逐镜生成**：每个镜头对应 `03_分镜\第N集镜头.md` 中的一个镜头，不得跳过/合并/自创镜头。
- **一镜一视频（2026-09-15 用户决策）**：一个视频 = 一个分镜 = 一个机位；视频内禁止出现多分镜、禁止场景跳变/机位切换/时空跨越。每镜提示词必须含单一性锁定句"本视频全程单一固定机位/单一运镜，禁止镜头切换、禁止场景跳变、禁止时空跨越"（en 版进 Detailed Description 与 Negative Prompt）。
- **输出固定为 `05_视频\第N集\videoX.mp4`**（X=镜头号），与分镜逐镜一一对应。
- **必须有提示词（CN/EN 双文件）**：每镜先产出 `视频X提示词_cn.md`（中文，供审核）与 `视频X提示词_en.md`（英文，提交用），两文件齐备且通过核对后才生成该镜视频；无提示词不得出片。参照角色/分镜双文件两段式方案，**严禁单文件多段式**。
- **先有场景资产图，用场景组合图合成视频**：media_1 用 `04_图片\场景\` 中本镜 **状态+朝向匹配** 的场景组合图（命名 `场景名-状态-面`，如 `小木家-白天-镜头朝东.jpg`；**不再沿用上个视频末帧**）。

### 1.3 职责边界
- 本环节生成**画面**，并在视频提示词「环境音效」段描述随画面生成的**一次性随机环境音**（开门/脚步/开关声等）。
- **可复用 / 需精确对齐画面触发点的音效由 step-07 音效环节独立生成**（见 ref\step-07\音效.md），本环节**不生成音效文件、不混音、不做BGM/配音**（BGM与配音由合成环节最后混入）。
- 按分镜提供台词文本作为提示词辅助，但**不混入任何音频**（多图参考01~20 系列无音频槽，环境音靠文字描述随画面生成）。
- **本环节不放大**：视频生成并评审后，放大归 08-3 放大子步骤（见 ref\step-08\放大.md）。
- **本环节不做抽帧、不做转场衔接片段**：已取消首尾帧抽帧与转场平滑片段（2026-09-07 用户决策），相邻镜头直接硬切，由合成环节（step-10）顺序拼接。

## 2. 输出产物（每镜三件套）

全部置于 `05_视频\第N集\` 下，一一匹配：
```
05_视频\第N集\videoX.mp4              # 真实视频（含环境音效与角色开口原声，无BGM配音；评审/合成用）
05_视频\第N集\视频X提示词_cn.md        # 视频提示词中文版（供审核；先于视频产出，评审依据）
05_视频\第N集\视频X提示词_en.md        # 视频提示词英文版（@xx模块式，提交 video_gen.py 用；先于视频产出）

05_视频\第N集\temp\                    # 临时内容（提交JSON等）
```

## 3. 固定命名规范（任何环节不得破坏）

- 文件名必须**一一匹配**：`videoX.mp4` ⇔ `视频X提示词_cn.md` ⇔ `视频X提示词_en.md`（X 为同一镜头号）。
- 本镜场景组合图（media_1，状态+朝向匹配）与角色/场景/道具参考图由 04 资产环节产出（见 ref\step-04\资产.md），本环节只引用、不重做。
- 若用户指定 X 为具体序号（如镜头1→video1.mp4），一律按用户给定序号命名。

## 4. 执行流程（每镜主线）

> 开工前置：04_图片 本集所需场景/角色/道具资产图（含状态×面组合图，命名`场景名-状态-面`）全部产出 + 04 资产评审与用户审核通过。本环节按 03_分镜 资产引用排定每镜参考媒体清单。

每镜按以下主线顺序推进，提示词编写见第 5 章：

| # | 步骤 | 关键动作 | 产出 |
|---|------|---------|------|
| 1 | 收集本镜资产 | 人物列表 + 场景 + 道具列表（按 03_分镜 资产引用） | 资产清单 |
| 2 | 排定参考媒体清单 | media_1=本镜状态+朝向匹配的场景组合图，media_2~N=角色→场景→道具 | 参考媒体清单 |
| 3 | 复制参考媒体进 input | 从 `04_图片\` 复制，`manju_vc/` 前缀 | input 就绪 |

| 5 | 提交并取回 | 调 video_gen.py（--prompt-file 指向 `视频X提示词_en.md`）→ 轮询 → 从 output 源件取回 | `05_视频\第N集\videoX.mp4` |
| 6 | 串行推进 | 一镜完成后再提交下一镜 | — |

## 4.1 脚本调用（video_gen.py，按参考图数量 N 直调）

> 本镜参考图排定后（media_1=本镜状态+朝向匹配的场景组合图，media_2~N=角色/场景/道具，N=参考图总数），直接调用封装脚本 `ref\step-08\scripts\video_gen.py`。脚本按 N 自动选档 `15.MinimaxH3 多图参考{N:02d}.json`（N=1~20），自动复制参考图进 input、填节点、提交、轮询、取回。**禁止临场手写工作流 / 逐节点填写**。

**必填参数**：
- `--images "路径1,路径2,..."`：本镜参考图**绝对路径，逗号分隔**。**第 1 张恒为本镜状态+朝向匹配的场景组合图（@图片1，如 `xx小屋-白天-镜头朝东.jpg`），第 2~N 张为角色/场景/道具（@图片2~N，每角色独立单图）**。逗号数量 = 参考图总数 N，脚本据此自动选档。
- `--prompt-file "视频X提示词_en.md"`（推荐）或 `--prompt "英文全文"`：@xx 模块式英文提示词，二选一。**用文件时传 `视频X提示词_en.md`（en 文件全文即提交 prompt，不再从单文件提取段落）**。
- `--seconds`：镜头时长（秒）。

**常用可选**：`--aspect-ratio 9:16 / 16:9`（默认16:9）、`--name <输出前缀>`、`--out-dir <05_视频\第N集>`、`--seed`、`--no-sage`（本机缺 triton 报错时加）、`--dry-run`（只构造不提交，先看档位/参数）。

**按参考图数量 N 的调用示例**（N 越大参考图越多，档位/填槽全部自动，命令写法一致，仅 `--images` 的图多几张）：

| N | 参考图构成（media_1~N） | 调用示例 |
|---|------------------------|---------|
| 1 | 仅场景组合图（无角色参考） | `python video_gen.py --images "G:\ManJu\04_图片\场景\xx小屋-白天-镜头朝东.jpg" --prompt-file "G:\ManJu\05_视频\第1集\视频1提示词_en.md" --seconds 5 --aspect-ratio 9:16 --out-dir "G:\ManJu\05_视频\第1集"` |
| 3 | 场景组合图 + 2 角色（或 1 角色 + 1 场景） | `python video_gen.py --images "G:\ManJu\04_图片\场景\xx小屋-白天-镜头朝东.jpg,G:\ManJu\04_图片\角色A.png,G:\ManJu\04_图片\场景\xx小屋-白天-镜头朝南.png" --prompt-file "G:\ManJu\05_视频\第1集\视频1提示词_en.md" --seconds 6 --aspect-ratio 16:9 --out-dir "G:\ManJu\05_视频\第1集"` |
| **5** | **场景组合图 + 2 角色 + 1 场景 + 1 道具** | `python video_gen.py --images "G:\ManJu\04_图片\场景\xx小屋-夜晚-镜头朝东.jpg,G:\ManJu\04_图片\角色A.png,G:\ManJu\04_图片\角色B.png,G:\ManJu\04_图片\场景\xx小屋-夜晚-镜头朝南.png,G:\ManJu\04_图片\道具.png" --prompt-file "G:\ManJu\05_视频\第1集\视频1提示词_en.md" --seconds 8 --aspect-ratio 9:16 --out-dir "G:\ManJu\05_视频\第1集"` |
| N>5 | 场景组合图 + 更多角色/场景/道具 | 命令写法不变，`--images` 继续往后加图即可；超过 5 张时建议先用 `--dry-run` 确认选档 `15.MinimaxH3 多图参考{N:02d}.json` 正确 |

> 提示：media_1=场景组合图（状态+朝向匹配）固定为第一张；media_2~N 排列顺序固定为 **角色 → 场景 → 道具**；同镜参考图超过 20 张时按 角色 > 场景 > 道具 优先取舍（脚本上限 N≤20）。
> 取回铁律：脚本从 ComfyUI output 源件 Copy-Item 取回（禁 8188/view 下载，会带水印），成功自动落 `--out-dir`。

## 5. 提示词编写（编写视频X提示词_cn.md / _en.md 双文件）

> 视频提示词按 `ref\step-08\template\视频提示词模板.md`**双文件两段式模板**编写：`视频X提示词_cn.md`（中文，供审核）+ `视频X提示词_en.md`（英文，@xx 模块式，提交 video_gen.py 用）。**参照角色双文件两段式方案，严禁单文件多段式**；本环节只写视频提示词。全片统一，禁止自由发挥、禁止缺段。

### 5.1 编写 `视频X提示词_cn.md`（中文版，供审核，先写后生成）

- 模板：`ref\step-08\template\视频提示词模板.md`「模板之A、cn 文件」
- 参考媒体：media_1=本镜状态+朝向匹配的场景组合图（@图片1，如 `xx小屋-白天-镜头朝东.jpg`；**不再沿用上个视频末帧**），media_2~N=角色/场景/道具（@图片2~N，每角色独立单图）
- 结构对齐角色方案：`# 提示词：视频X（镜头X）cn` → `# 正向提示词`（下挂 `## 风格` / `## 布局` / `## 详细描述` 三个二级段，中文连贯描述，按序涵盖 ① 参考媒体清单 ② 主体定义 ③ 镜头内容（分段时间轴版，含台词绝对起止时刻）④ 空间方位 ⑤ 空间逻辑描绘 ⑥ 人物一致性 ⑦ 发声约束 ⑧ 环境音效 ⑨ 风格锚点，不另起子标题）→ `# 反向提示词`（固定负面约束列表）
- 中文段为**供审核文本**，非提交字段；与 en 文件内容语义一致

### 5.2 编写 `视频X提示词_en.md`（英文版，提交用）

- 模板：`ref\step-08\template\视频提示词模板.md`「模板之B、en 文件」
- 结构对齐角色方案：`# Video Prompt: Video X (Shot X) en` → `# Positive Prompt`（下挂 `## Style:` / `## Layout:` / `## Detailed Description:` 三个二级段）→ `# Negative Prompt`
- **`## Detailed Description` 段为 @xx 模块式逐字全文**（subject_definitions / @ / summary / retention_analysis / detailed_description / overall_soundscape / 可选 non_diegetic_music），为实际提交主节点 prompt 字段全文
- 硬闸：分段时间轴禁止简化/省略；禁止出现制作指令词

### 5.3 提示词编写模板（路径引用，全片统一）

- 模板单独成文档：`ref\step-08\template\视频提示词模板.md`，含「模板之A、cn 文件结构」「模板之B、en 文件结构与 @xx 模块式英文规范（含完整英文示例）」「通用规则」，本环节不内嵌重复模板
- 通用规则要点：视频提示词双文件（cn/en 分离）为唯一书写标准；en 的 `Detailed Description` 必须为实际提交逐字全文；@xx 模块式转译（subject_definitions 用 @图片N 定义主体，台词中文原句用 `<d>[Chinese]…</d>` 保留）；时间轴/镜头/运镜/描述一体；禁止制作指令词；镜头内容一律分段时间轴版
