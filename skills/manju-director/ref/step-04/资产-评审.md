> 加载时机：资产图片环节产出后执行评审时。评审规则不符即打回。

> **用户审核**：资产图片评审通过后，**必须将资产图片产出提交用户审核确认**，用户确认后才进入下一环节（声线）。未获用户确认不得自动放行。

## 一、评审流程与打回规则
1. 读取 `00_项目\评审\` 下对应环节的评审结论
2. decision = "approved" → 放行，进入下一环节
3. decision = "revision" → 记录问题清单 → 调度对应环节重写
4. decision = "escalated" → 最高级，通知用户决策
5. **打回规则**：同一环节最多打回 5 次；第 6 次仍不通过，升级给用户决策，不得无限打回

## 二、评审规则（必须逐项验证，不符即判 ❌ Revise）
1. **数量一一对应**：提示词文件与资产图片一一对应，不缺漏（每资产 = `_cn.md` + `_en.md` + 图片三件套）
2. **存储位置**：产物落于 `04_图片\<角色|场景|道具>\<名称>.jpg/.png`，位置无错
3. **提示词内容符合模板**：以 `ref\step-04\template\资产提示词模板.md` 为**唯一标准**逐项核对——CN/EN 双文件两段式齐备（cn=`# 正向提示词`[风格/布局/详细描述]+`# 反向提示词`，en=Positive/Negative）、固定模块（风格/布局/反向）与模板逐字一致且跨资产一致、仅详细描述按资产差异化、不引入模板之外额外段、反向含固定负面约束；不符即 ❌ Revise
4. **真实产物 + AIGC 零容忍**：生成图为真实文件（非空、可打开），空文件/占位 → 判 ❌ Revise；提示词文件含 AIGC 溯源块（`AIGC:` / Label / ContentProducer / ProduceID / ReservedCode1 / ContentPropagator / PropagateID / ReservedCode2）或文字水印（内容由AI生成，仅供参考）→ 判 ❌ Revise（删除后再提），不得放行
5. **状态×面组合（如有，走图片编辑）**：状态×面组合图（如 `xx小屋-夜晚-镜头朝东` / `xx小屋-雨天-镜头朝南`）为基于原场景图的**图片编辑**产物（工作流 `02.1.FLUX2-图片编辑.json` + `image_edit_gen.py`），**布局/机位面/构图与原场景图一致，仅状态（环境/天气/光线/氛围）或朝向变化**；命名 = `场景名-状态-面`，落 `04_图片\场景\`；提示词 en 的 Positive 含"保持原场景布局/机位/构图/视角不变"约束；同规则 4 真实产物 + AIGC 零容忍；不符即 ❌ Revise

## 三、内容审查（仅当前模型支持视觉审图时执行）
- **角色图**：立绘+三视图版式（左立绘+右正/侧/背），外貌（发型/发色/服装）与资产文件一致
- **场景图**：按机位面拆分（每面一张），本面平视视角（正对本面，人眼高度，非俯视），布局与资产文件"布局"吻合（摆件不漂移），同一场景各面参考图摆件位置一致仅朝向不同
- **道具图**：双视图（正面+侧面），两视图一致
- 跨图一致：发型/服装/特征引用资产文件，不漂移
- 美术风格符合 `立项.md` 的 `art_style`；分辨率符合 `aspect_ratio`
- 模型不支持内容审查时：不做内容审查，提醒用户自行审查；**不允许退化为数量/命名核对**

## 四、不一致处理
角色、场景、道具、风格任一不一致 → 先提醒用户是否继续，不主动继续/放行

- RV-02: ...
