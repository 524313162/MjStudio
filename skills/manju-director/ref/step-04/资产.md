## 资产图片环节（图片制作）

**职责**：根据资产白名单与资产文件，重构标准提示词并真实生成全部资产图片（角色/场景/道具三类；BGM/音乐不归本环节）：
- **角色**：一张图 = 立绘 + 三视图（画面左侧全身正面立绘，右侧正/侧/背三视图）
- **场景**：按「状态 × 机位面 × 空间区域」三维度拆分（全貌总纲见 ref\assets.md），**每个被分镜引用的 场景名-状态-面 组合**一张**平视该朝向全景图**（人眼高度，正对本面，非俯视；**提示词必须含详细空间布局描述点**与**本面朝向/本状态**，供视频提示词"空间逻辑描绘"引用；同一场景不同面/不同状态参考图共享同一套全貌总纲布局，仅朝向/状态不同）
- **道具**：双视图（左右两个视角）
- **提示词与图片分开落盘**：每个资产产出独立提示词文件（CN/EN 双文件两段式，见下模板），再生成同名图片，不写入资产文件内

**输出结构**（提示词与图片成对落盘；提示词文件 = **CN/EN 双文件两段式**（`<名称>_cn.md` + `<名称>_en.md`），图片 = `<名称>.jpg/.png`，`<名称>` = 资产名，所有资产统一）：
```
04_图片\
├─ 角色\阿乐_cn.md + 阿乐_en.md   # 双文件两段式提示词（cn 供审核、en 填节点 67/71 提交）
├─ 角色\阿乐.jpg                  # 生成图（一张图 = 立绘+三视图）
├─ 场景\便利店外·雨夜街道-夜晚-正面_cn.md + 便利店外·雨夜街道-夜晚-正面_en.md
├─ 场景\便利店外·雨夜街道-夜晚-正面.jpg     # 每个状态×机位面组合独立建资产/独立出图（-状态-正面/-状态-左侧/…，摆件一致仅朝向/状态不同）
└─ 道具\旧硬币_cn.md + 旧硬币_en.md
   └─ 道具\旧硬币.jpg
```
> 提示词文件是**评审依据**。图片必须是真实生成文件，禁止空文件占位。

**提示词文件固定模板（双文件两段式，唯一标准，勿用单文件多段式）**：每个资产提示词 = **CN/EN 双文件**——`<名称>_cn.md`（中文，供审核）+ `<名称>_en.md`（英文，提交 ComfyUI 节点 67/71）。**完整模板（含 cn/en 结构、角色/场景/道具三分类版式模板、固定负面约束）见 `ref\step-04\template\资产提示词模板.md`**，本环节不内嵌重复模板。


**生成流程**：对白名单内每个资产：先写提示词文件（真实内容），再**必须调用封装脚本 `ref\step-04\scripts\zimage_gen.py`（禁止临场手写工作流 JSON / 逐个填节点 / 临场写接口代码）**：
```
# 角色图
python ref\step-04\scripts\zimage_gen.py --type character --name <资产名> --positive "<正向EN>" [--negative "<反向EN>" --seed <n>]
# 场景图
python ref\step-04\scripts\zimage_gen.py --type scene --name <资产名> --positive "<正向EN>"
# 道具图
python ref\step-04\scripts\zimage_gen.py --type prop --name <资产名> --positive "<正向EN>"
```
- 脚本按 `--type` 自动选模板工作流：角色 → `01.文生图（ZImage）-角色视图.json`；场景 → `-场景俯视图.json`（文件名为历史旧称，语义为场景正常平视视角，勿按文件名理解为俯视）；道具 → `-道具双视图.json`
- 脚本自动填节点 67/71/68/70/9、生成 `manju/<类型>/<资产名>` 前缀、用内联提交引擎自动提交轮询
- **取回**（脚本内置）：从 ComfyUI output 目录源件直接 Copy-Item（严禁 8188/view 下载通道，会带"AI生成"角标水印），存 `<名称>.jpg/.png` 到 `04_图片\<类型>\`，可经 `--out-dir` / `--comfy-input` 落盘。禁止空文件占位；接口未就绪 → 如实报告阻塞

**场景图生成顺序（硬约束，2026-09-15 用户决策）**：**先为每个区域生成全貌底图**（基准状态+默认朝向一张），**再基于底图对每个被分镜引用的 状态×面 组合做图片编辑变体**——优先生成场景图，然后各状态/朝向变体一律用图片编辑（保持同一场景布局、机位面、构图不变，只换状态（环境/天气/光线/氛围）或朝向），**禁止对变体重新文生图**：
- 编辑工作流 = `ref\step-04\workflows\02.1.FLUX2-图片编辑.json`（单参考图节点 76 = 原场景图，1024x576 16:9；提示词填 92:113）
- 封装脚本 = `ref\step-04\scripts\image_edit_gen.py`（禁止临场手写工作流 JSON / 逐个填节点 / 临场写接口代码）
- 提示词与图片分开落盘：每变体产出 `<变体名>_cn.md` + `<变体名>_en.md`（CN/EN 双文件两段式，en 的 Positive 描述编辑目标环境/氛围并**强调"保持原场景布局/机位/构图/视角不变"**，Negative 沿用资产固定负面约束）+ `<变体名>.jpg`，落 `04_图片\场景\`
- 变体命名 = `场景名-状态-面`（如 `xx小屋-夜晚-镜头朝东`、`xx小屋-雨天-镜头朝南`；原 `xx小屋-大雨天`/`xx小屋-凌晨` 旧格式并入状态维度，统一为 `场景名-状态-面`）；生成后该变体即视为独立场景资产，视频环节按镜头环境+机位直接引用对应组合场景图
- 用法：
  ```
  # 大雨天-朝东变体
  python ref\step-04\scripts\image_edit_gen.py --image "04_图片\场景\xx小屋.jpg" --prompt-file "04_图片\场景\xx小屋-大雨天-镜头朝东_en.md" --out-name xx小屋-大雨天-镜头朝东 --out-dir "04_图片\场景" --jpg
  # 凌晨-朝南变体
  python ref\step-04\scripts\image_edit_gen.py --image "04_图片\场景\xx小屋.jpg" --prompt-file "04_图片\场景\xx小屋-凌晨-镜头朝南_en.md" --out-name xx小屋-凌晨-镜头朝南 --out-dir "04_图片\场景" --jpg
  ```
- 取回（脚本内置）：从 ComfyUI output 目录源件直接 Copy-Item（严禁 8188/view 下载通道，会带"AI生成"角标水印），转 jpg 落 `04_图片\场景\`；禁止空文件占位；接口未就绪 → 如实报告阻塞

**注意事项**：
- 只生成**白名单内**资产；提示词文件先写后出图，双文件两段式（cn/en）缺一不可
- 角色一张图（立绘+三视图合一）；场景一张正常平视视角全景图（非俯视）；道具一张双视图
- 图片命名：所有资产图片统一 `<名称>.jpg` / `<名称>.png`（不带视角后缀），配套提示词文件 = CN/EN 双文件 `<名称>_cn.md` + `<名称>_en.md`
- **场景按区域拆分生成**（每个区域场景资产都要生成一张该区域参考图，禁止"只给全景一张图然后所有镜头共用"）
- 提示词正文严禁 `---` 分隔线
- **重新生成前清理错误产物**：重新生成某资产前，**先清理该资产目录下上一轮的错误产物**（错误图片/残留提示词），再生成，避免新旧混存、错误提示词被误当作终稿提交；提示词文件是评审依据，**严禁在不告知用户的情况下覆盖已确认的提示词文件**，改动需留痕/先备份。
