# 漫剧多Agent制作流程 · 设计总览(v3)

### 工作目录（存储路径）
- **每次立项第一件事 = 先询问用户存储路径**；用户未指定 → 默认 `D:\00-Manju-Workspace`
- **用户给出路径 → 立即更新本项目 立项.md 中的记录，并记住该路径，下次立项默认沿用用户给的路径**，不再回退到默认值
- 若目录不存在/无法写入 → 导演必须询问用户指定存放位置
- 项目目录 = `<工作目录>\<项目名>\`(项目名由用户提供或从需求提炼)
- **立项文档位置 = `<工作目录>\<项目名>\00_项目\立项.md`**（导演维护，MD格式，字段精简）

### 立项引导（导演开工必做，用户没想到的必须主动问）
立项不能只记"项目名+集数"。以下关键项用户通常不会主动提，但决定全流程产物形态，导演必须逐项引导确认，不得擅自假设：
- **A. 必问**：① 画幅/目标平台（竖屏9:16漫剧主流 vs 横屏16:9）；② 题材与受众（奇幻/都市/治愈/搞笑…儿童/成人）；③ 美术风格（水彩/日系动漫/简约/写实…）；④ 配音语言（普通话/方言/其他）；⑤ 原创或改编（版权）；⑥ **总集数**（10~40集常见20~25集，不得默认1集）
- **B. 建议确认**：⑦ 片头片尾（**默认无**，仅用户明确要求才加）；⑧ BGM风格；⑨ 交付物（**第N集_原生版.mp4 + 第N集_配音版.mp4 双版成片，均硬压简体中文字幕**）；⑩ 每集时长（默认≥2分钟/集）
- **C. 引导方式**：逐项提问给选项和默认值；用户"随便/你定"的项按合理默认确定并**记录进 立项.md**，不可事后漂移
- 全部确认后写入 `00_项目\立项.md`(MD格式,固定模板见本技能)，后续所有 Agent 只读该文件，不再重复问用户

### 美术风格锚点（全剧风格统一的根，提示词全局约定）
- 立项确认美术风格后，翻译为**风格锚点块**（正向强力描述 + 反向排雷词），**全项目所有生成（图片/视频）统一引用同一段**，跨资产不得换词
- 例（日系动漫）：
  - 正向：`日本2D手绘动画电影美术风格，赛璐璐平涂上色，清晰深色描边线稿，扁平色块阴影，高饱和明快色彩，非写实、非照片、非3D渲染、非厚涂`
  - 反向：`写实风格，真人，照片质感，3D渲染，CGI，厚涂油画，肌理笔触，体积感过强，电影实拍感`
- 其他美术风格立项时同样产出风格锚点块（风格名+技法特征+排除词），写入立项.md

### 真实产出原则(取消一切模拟,全真实产出)
- **所有产物必须真实生成,禁止空文件占位、禁止任何"模拟模式"**。旧版"模拟与真实边界/模拟模式"已废除,不得再以"接口未联调"为由创建空文件充数
- **文本/规划类产物**:剧本、资产、分镜、视频提示词、资产内提示词区块、台词清单.json、BGM使用对照、字幕SRT → 真实写入完整内容
- **生成类产物**:图片(角色/场景/道具)、视频(每镜头mp4)、音频(BGM/声线种子wav) → 必须通过真实工作流生成(见本技能 9.4 登记的工作流),提交→轮询→取回真实产物文件
- **导出类产物**:双版成片(原生版/配音版,含字幕烧录) → 必须通过 ffmpeg 真实合成
- **阻塞即报告**:接口未联调/环境未就绪导致某环节无法真实产出时,该环节视为**未完成/阻塞**,Agent 必须向导演和用户如实报告阻塞原因与所需条件,不得用空文件假装完成、不得评审放行

### 职责边界(重要)
- **混音唯一负责方 = 合成Agent**:视频Agent产出画面+角色开口原声(原声台词由第9步配音环节去原声换音色,产出仅台词声的_配音.mp4);BGM 与音效文件统一在合成阶段混入,不重叠;**可复用/精确对齐音效文件由音效环节(step-07)生成,合成环节按画面触发点混入**;**换音色唯一负责方 = 配音Agent(step-09)**:分镜片段原声全去、仅留换音色台词声,拼接混音仍归合成(step-10)
- **字幕唯一负责方 = 合成Agent**:从台词清单.json 生成简体中文字幕(对话+旁白,不增字不减字),时间轴取台词清单,双版硬压烧录(原生版/配音版都要)
- **音效唯一负责方 = 音效Agent(step-07)**:仅生成**可复用/需精确对齐画面触发点**的音效(鸟鸣/风声/水花/特效音)——复用 09.STABLE-BGM.json 切 SFX 档生成,落 06_音频\音效\;一次性随机环境音(开门/脚步/开关声)不单独生成,由视频Agent在视频提示词中描述、随画面生成
- **声线种子 = 视频生成取声(声线环节,step-05)**:声线环节在资产图片产出后、音乐之前执行,为全部出场且需配音角色逐一配置专属声线(含旁白)。方法:用视频工作流生成一段该角色念自我介绍台词的短视频(如"我是XXX,我的名字叫XXX,很高兴认识你"),从这段视频提取音频作为该角色的声线种子,全剧复用;**所有角色(含旁白)统一此法,无基础音兜底**;**种子配齐后进入后续环节,本环节不做逐句配音、不生成台词语音(逐句配音换音色归第9步配音环节,目标声线=本环节种子)**
- **片头片尾默认无**:仅立项.md 勾选时才产出；视频Agent出画面模板;音乐Agent出曲;合成Agent拼接混入
- **旁白 = 角色(只有声音)**:登记声线、配专属种子,不出图、不进合并图;无画面原声,种子用视频生成取声(与其它角色同法,无基础音兜底)

- **视频提示词必须含空间逻辑描绘**:前提是场景提示词文件详细描述段要有"空间逻辑描述点"(并入详细描述段,不单独成段);视频提示词据此+分镜空间方位写出人物/物体空间逻辑关系
