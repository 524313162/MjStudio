> 加载时机：编剧/分镜/视频/配音/合成环节需要时长估算时，或评审核对时长时。

## 时长估算
# 漫剧时长估算

### 适用场景
- 编剧:创作剧本时自检"这一集能不能演满2分钟""台词会不会不够/太多"
- 分镜:给每个镜头估算 duration_sec
- 配音:给每句台词分配时间戳
- 合成:核对全片时长

### 核心参数(可被 立项.md 覆盖)
- 默认每集目标时长:`≥ 120 秒`(2分钟,用户要求"不低于2分钟")
- 人语速:**情绪语速分级**(见下方分级表,非匀速;仅作分镜/剧本预排,精度以原视频台词时间戳为准)
- 台词停顿:每条台词 +0.4 秒(基础)
- 动作/叙事段:约 2.5 秒/条
- **环境音效:不单列计时**(开门声/脚步声/开关声等随机一次性环境音在视频生成提示词中详细描述,随视频画面生成,不占配音时长);**可复用/精确对齐音效**(鸟鸣/风声/水花/特效音等)由 step-07 音效环节按 SFX 档规则生成(环境6~15s/单发1~3s),时长由音效文件本身决定、不占镜头/配音时长,合成环节按分镜出现点表混入
- 场景切换:(场景数-1) × 1.5 秒
- 片头/片尾:**默认无**(仅立项.md 明确勾选时各计约 10 秒)

### 情绪语速分级(不同情绪耗时不同,禁止匀速估时)
> 台词实际耗时随情绪/语气波动,分镜/剧本预排时按情绪查表给**区间**,不追求精确。

| 情绪档 | 语速 | 停顿加成 | 说明 |
|---|---|---|---|
| 平静叙述(默认) | 4字/s | +0.4s/句 | 旁白、日常对话、交代信息 |
| 焦急/激动 | 5.5字/s | +0.2s/句 | 催促、争执、急促问答 |
| 大声呼喊 | 6字/s | 句尾拖音 +0.5s | 隔岸喊话、情绪顶点 |
| 缓慢/悲伤 | 2.5字/s | +0.8s/句 | 哭腔、回忆、沉重告白 |
| 迟疑/吞吐 | 3字/s | +1.0s/句 | 犹豫、欲言又止 |

**标点停顿加权**(追加在停顿加成之上):逗号 +0.3s / 句号 +0.5s / 省略号 +0.8s / 破折号 +0.6s / 感叹问号 +0.4s。

**用法**:分镜中台词时间轴 = 按情绪档位算出的**区间**(如 `[3.2s~4.5s]`),只保证粗排合理;台词真实时间由第9步配音环节 faster-whisper 实测校准(见 ref\step-09\配音.md)。

### 时长公式(预排区间版)
```
台词秒     = Σ(每条台词字数 ÷ 该句情绪档语速) + 停顿加成 + 标点加权 → 取区间
旁白秒     = 旁白按角色台词计,按"平静叙述"档
动作秒     = 动作/叙事段条数 × 2.5
环境音效   = 0(随视频画面生成,不单列)
切换秒     = (场景数 - 1) × 1.5
片头片尾   = 默认0(立项勾选时 10+10)
单集总长   = 台词秒 + 旁白秒 + 动作秒 + 切换秒 + 片头片尾(预排值,合成以配音实测为准)
```

### 达标标准
- 单集总长 **≥ 120 秒**(最低要求;推荐 120~150 秒,宁多勿少)
- 若低于120秒 → 需扩充剧情/台词/动作,避免"台词不够"或"画面空转"
- 若明显超过(如>180秒)→ 检查是否台词过多/节奏拖沓,适当精简

### 镜头时长硬约束(重要,分镜必须遵守)
- **单个镜头时长控制在 5~10 秒**,不能太短、不能太长(模型生成时长与耗时成正比,15s 太长;下限为模型训练最短帧约5s/124帧)
- 镜头时长 = 该镜头内 台词秒 + 动作秒 之和（**环境音效不单列计时**，随画面生成）
- 超 10 秒 → 必须拆成多个镜头(把该镜头内容按动作/台词切段拆分)
- 不足 5 秒 → 并入相邻镜头,或扩充动作/音效/过渡,不能留"碎片镜头"
- 分镜拆镜头时以"5~10秒容量"为单位:先按剧本场景分段,再逐段套用公式确认时长
- 检查:镜头数 × 平均7~8秒 ≈ 该集正文时长(不含片头尾),可反推镜头数量是否合理(120秒 ≈ 15~24 个镜头)

### 检查清单(评审用)
- [ ] 每集台词量是否与该集时长匹配(按公式逐项加总,不以字数粗估)
- [ ] 是否有大段无台词、无动作的空白
- [ ] 片头片尾(如立项勾选)是否已计入时长
- [ ] 分镜每个镜头的 duration_sec 之和 ≈ 该集总长
- [ ] **每个镜头 duration_sec 是否都在 5~10 秒内**(超10s必拆,不足5s必并)
