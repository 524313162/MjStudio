## 配音环节（配音，新增第9步）

**职责**：把视频环节产出的**每个分镜视频**（`05_视频\第N集\视频X.mp4`）中角色原声里的台词，换成该角色专属**声线**（`06_音频\声线\<角色>_种子.wav`，step-05 声线环节产出），得到**只有台词声音**的分镜片段（`视频X_配音.mp4`）。拼接混音归 step-10 合成环节。

**台词真实时间以 ASR 实测为准**：台词清单（`03_分镜\第N集台词.json`）里的 `start_sec`/`end_sec` 是分镜估算值，**不是最终依据**。配音环节对每个分镜视频**用 faster-whisper 离线转写实测**台词在视频内的真实起止秒，按实测裁剪、按实测贴回（实测可能与台词清单略有出入，以实测为准）。

**核心流程（逐镜）**：
1. 读取当前集所有分镜视频 `05_视频\第N集\video*.mp4`（衔接视频已取消，2026-09-07 用户决策）+ 台词清单 `03_分镜\第N集台词.json`（含 `seq/shot/character/text/emotion/start_sec/duration_sec/end_sec/file`）
2. 对每个有台词的镜头（台词清单按 shot 归组，一镜可能一句或多句）：
   - **提取音轨**：ffmpeg 从镜头视频提出全音轨（ASR 用 16k 单声道；裁剪用 44.1k 立体声）
   - **ASR 实测**：faster-whisper（模型 small，`D:\faster_whisper\venv\Scripts\python.exe D:\faster_whisper\transcribe_timestamps.py <音频> small`）转写镜头音频，得到逐句真实 `start/end`
   - **定位台词**：把台词清单该句文本与 ASR 段做匹配（文本以台词清单为准、时间以 ASR 实测为准）；一句台词可能被 ASR 切分成多段，合并相邻命中段取完整时间跨度 `[start,end]`（段间小间隙 ≤1.5s 视为连续）
   - **裁剪原声**：按实测区间（前后各留 0.2s padding）把该镜原声台词段裁剪出来
   - **换音色**：调 **32.FL-CosyVoice3-音频声音转换.json**（封装为 `voice_convert.py`）把裁剪原声的音色换成该角色声线（`06_音频\声线\<角色>_种子.wav`）→ 得到换音色台词 wav
   - **去原声贴回**：整段原声全部去掉（静音），把换好音色的台词声贴回原实测时间点，得到 `视频X_配音.mp4`（只有台词声音）
3. 无台词镜头（台词清单无该 shot）：去掉原声（静音）产出 `_配音.mp4`
4. 每句换音色后的台词 wav 另存 `06_音频\第N集\<file>`（file 取台词清单 `file` 字段）

**脚本：`配音吧`（ref\step-09\scripts\配音.py）**

```powershell
# 用法（一键执行第N集全部镜头配音）
python "…\manju-director\ref\step-09\scripts\配音.py" --project "<项目根>" --episode N
```

参数：
| 参数 | 默认 | 说明 |
|---|---|---|
| `--project` | 必填 | 项目根目录（含 03_分镜 / 05_视频 / 06_音频） |
| `--episode` | 必填 | 第N集 |
| `--voice-dir` | `06_音频\声线` | 声线目录 |
| `--asr-model` | `small` | faster-whisper 模型 |
| `--padding` | `0.2` | 裁剪台词段前后多留秒数 |
| `--out-suffix` | `_配音` | 配音版视频后缀 |
| `--dry-run` | 关 | 只做 ASR 实测打印定位结果，不裁剪/不调工作流/不产出 |
| `--keep-temp` | 关 | 保留 temp 中间音频 |
| `--comfy-input/--comfy-output/--server/--interval/--timeout/--max-retry` | 默认 | 透传给 voice_convert.py（32 工作流提交引擎） |

内部依赖：`voice_convert.py`（32 工作流固定化封装，ref\step-09\scripts\）、`ref\step-09\workflows\32.FL-CosyVoice3-音频声音转换.json`（收拢备份，运行读取）。

**voice_convert.py（32 工作流封装）**：传 `--seed-audio`（目标音色声线）+ `--content-audio`（内容音频），自动把两音频复制进 ComfyUI input、填节点 1/2/4（LoadAudio×2 + VoiceConversion）、内联提交引擎提交→轮询→从 output 源件取回换音色音频。节点映射：1=目标音色、2=内容音频、4=VoiceConversion(source=2,target=1)、5=PreviewAudio、6=SaveAudio。

**输出**：
```
05_视频\第N集\视频X_配音.mp4       # 分镜片段：原声全去，仅台词声（换音色）贴在 ASR 实测位置
06_音频\第N集\<台词清单 file 字段>    # 每句换音色台词 wav（如 镜头2_小墨_台词2.wav）
```

**注意事项**：
- **以 ASR 实测为准**：台词清单 `start_sec` 是分镜估算，裁剪/贴回一律用 faster-whisper 实测时间（用户示例：清单给 6.5~10.4，实测可能 7~10.4，以实测为准）
- **原声全去**：配音版分镜片段中无台词的时段是静音（用户要求"分镜片段所有声音去掉，留下台词声音"）；环境音/BGM 由合成环节统一处理
- **ASR 定位失败的镜头**：如实报告该镜台词未在 ASR 结果中定位（原声里可能没有清晰台词），**跳过该镜不产出配音版**，不静默伪造；用户可人工核对原声后决定补录/重生成
- **声线必须存在**：`06_音频\声线\<角色>_种子.wav` 缺失 → 该镜失败，先回 step-05 声线环节配齐
- **一镜多句台词**：按句分别实测、分别裁剪、分别换音色，多段依次贴回（amix 顺序叠放）
- 本环节**不拼片、不混 BGM/音效、不烧字幕**，那些归 step-10 合成环节（唯一混音方）
