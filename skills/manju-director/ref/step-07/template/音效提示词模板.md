# 音效提示词模板（双文件两段式）

> 适用范围：音效环节（step-07）为每个可复用/精确对齐音效编写独立提示词时使用，对齐图片资产提示词范式。
> 文件组织：每音效提示词 = **CN/EN 双文件**——`06_音频\音效\<音效名>_提示词_cn.md` + `<音效名>_提示词_en.md`；音频类**无布局段**。
> 结构：cn = `# 音效提示词：{音效名}（{类型}）cn` + 一级段 `# 正向提示词`（下挂 `## 风格` / `## 详细描述`）+ 一级段 `# 反向提示词`；en = `# SFX Prompt: {音效名}（{类型}）en` + `## Positive Prompt`（`Style:` / `Detailed Description:`）+ `## Negative Prompt`。
> **禁止无约束的自由散文式单段描述、禁止旧版固定版式+中英四段+参数化锚定多段式**——参数化硬约束并入风格段、触发时机并入详细描述段。

## 模板一：cn 文件（`<音效名>_提示词_cn.md`）

```markdown
# 音效提示词：{音效名}（{特写拟音/环境底噪/角色声}）cn

## 正向提示词
风格：纯净单音源{特写拟音/环境底噪/角色声}，仅输出「{音效名}」这一个声源，不混入人声/台词/音乐/其他音效/环境底噪；干声无混响无空间残留，声像居中，动态{短促利落/平缓稳定}；高保真 48kHz 24bit，起音瞬态清晰不削波，尾音自然衰减无爆音；{时长 {单发 1~3s / 环境 6~15s}，硬约束落 --duration}；{电平：前景/背景 {X} LUFS}；{频段：{主要频谱区间}}
详细描述：{声音源（什么发出的）/ 材质（金属/水/木质…）/ 空间（室内/室外/混响）/ 动态（起止渐强渐弱/单发/循环）四要素齐全的中文完整描述 + 触发时机（镜头号+镜头内秒+全局秒，来自分镜「本集音频出现点表」）}

## 反向提示词
{排除项：人声/台词/音乐/混响尾音/爆音削波/持续噪音…}
```

## 模板二：en 文件（`<音效名>_提示词_en.md`）

```markdown
# SFX Prompt: {音效名}（{特写拟音/环境底噪/角色声}）en

## Positive Prompt
Style: {与中文风格段对应的英文}
Detailed Description: {与中文详细描述段对应的英文，供 sfx_gen.py --prompt 提交}

## Negative Prompt
{与中文反向对应的英文，供 sfx_gen.py --negative 提交}
```

## 编写要求

- **对应资产**：提示词文件开头注明 `对应资产：02_资产\音效\{资产文件}.md`；**参考音频硬锚**：资产文件「参数化锚点」有参考音频则写路径，无则"以资产文件「声音特征+参数化锚点」为准"
- **应用判定来自分镜**：读 01_剧本 + 03_分镜「本集音频出现点表」，梳理每个音效的触发时机（拟音/氛围音效必须精确到触发秒，供合成混入对齐画面）
- 描述要素：声音源（什么发出的）/ 材质（金属/水/木质…）/ 空间（室内/室外/混响）/ 动态（起止渐强渐弱/单发/循环）
- cn/en 两文件段落结构一一对应，内容语义一致（cn 中文 / en 英文）
