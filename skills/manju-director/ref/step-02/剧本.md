## 剧本环节（编剧）
**职责**：根据 `00_项目\立项.md`（世界观、每集时长、总集数）创作**完整故事**剧本（**只做剧本，不做资产**）：
1. 故事必须有名称、分集数与立项一致（如20~25集，不是只写1集）
2. **单集时长是硬指标**：每集必须达到 立项.md 的目标时长（默认 ≥2分钟/120s）。**禁止自由发挥缩短**——写完后必须按 本技能 timing.md 公式逐项自算并附在文件内，不达标 = 不合格，需扩充剧情直到达标
3. 每集故事必须**完整**（起承转合：起因→发展→转折→结果/钩子），不能是片段、不能戛然而止
4. 台词、剧情、场景充分考虑：**不出现台词不够或过多的问题**
5. 一个故事有多个章节，每个章节至少有 1 个或多个剧情热点
6. 剧本必须包含**角色列表**（本集全部出场角色，含一次性角色与旁白），供分镜环节提取资产
7. **环境音效（开门声/脚步声/开关声等）不必写成配音项**：由分镜/视频提示词中详细描述，随视频画面生成，不进入台词清单；**可复用/精确对齐音效（鸟鸣/风声/水花/特效音等）也不写成配音项**，由分镜提取为音效资产、step-07 音效环节生成（音效独立成 step-07 环节），不进入台词清单

**时长自算模板（每集必填，写入剧本文件末尾）**：
```
台词秒 = Σ(每条台词字数÷4) + 0.4×台词条数 = ?s
旁白秒 = ?s（旁白按角色台词计，一般不常出现）
动作秒 = 动作条数×2.5 = ?s
环境音效 = 0（开门声/脚步声等在视频提示词中描述，随画面生成，不占配音时长）
切换秒 = (场景数-1)×1.5 = ?s
片头尾 = 0（默认无；立项勾选时 10+10）
合计 = ?s  （必须 ≥ 120s，不足→继续扩写直到达标）
```
**若自算低于目标时长 → 本集不合格，必须扩写剧情/台词/动作后重新自算，不得以"演示/示例/大概"交差。**

**输出**：
- `01_剧本\第N集.md`：每集一个文件（**不含任何资产文件**；资产由分镜环节从剧本提取）

**剧本文件格式（01_剧本\第N集.md）**：
```markdown
# 第N集：本集标题

## 本集概要
（100字概括）

## 本集角色列表
- 主角：角色名（一句话身份，如：小蝌蚪，主角）
- 配角：角色名（一句话身份）
- 一次性角色：角色名（一句话身份，凡有台词必须列出）
- 旁白：无画面，仅声音（需配音）
（列出本集全部出场角色；分镜环节据此提取角色资产）

## 剧情热点
- 热点1：……
- 热点2：……

## 时长估算
（按 本技能 timing.md 公式列出：台词秒/动作秒/切换秒，合计≥120s；片头片尾默认无，仅立项勾选时计入）

## 片头/片尾
- 片头：无（默认）/ 有（仅在立项.md勾选）
- 片尾：无（默认）/ 有（仅在立项.md勾选）

## 场景N：场景名称（时间/地点）
叙事内容描述...
> 角色名（动作/情绪）
> "台词内容"
（环境音效如开门声在画面描述中体现，如：开门声响起，爸爸推门进来）
```

**（资产信息不在本环节产出：角色/场景/道具/BGM/音乐/音效等资产统一由分镜环节从剧本提取，见 ref\step-03\分镜.md。本环节只需保证剧本含完整的本集角色列表。）**

**注意事项**：
1. 每集必须满足时长（≥2分钟），写完后自算并附在文件内；**不达标禁止交稿**
2. 每章节至少 1 个剧情热点（冲突/转折/钩子/笑点/泪点等）
3. 台词量与画面匹配：不要整集全是旁白、也不要密集台词无留白；**旁白要克制**，一般剧情靠角色对话推进，旁白只用于关键点（如法官宣读、画外收尾），旁白列入本集角色列表
4. 角色行为符合世界观；角色声线/外貌由分镜环节提取资产时一次性定稿，跨集不得漂移
5. 使用 `>` 标台词、`` 标动作/情绪；环境音效直接写在画面描述里（"开门声响起…"），**不用【】包裹做配音项**
6. 剧本需详细、完整，可被分镜直接拆分
7. 明确标注每集是否有片头/片尾（**默认无**，仅立项勾选时才有），供视频/音乐/合成三环节使用
8. 剧本内容按"每镜头5~10秒"的容量组织叙事段（一段画面动作或几句台词≈一个镜头），便于分镜直接切分
